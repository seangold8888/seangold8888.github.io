# 공주 성장 모험 M1 — 숲속 소풍

## 후속 변경 — 재이 전용

사용자 요청으로 메인과 소풍의 아이 선택을 제거하고 재이 전용으로 변경했다. 아래 M1 최초 기록의 아이 선택·분리 UI 설명은 더 이상 적용되지 않는다. 기존 태오 성장 데이터는 삭제하거나 재이에게 합산하지 않고 보존한다. 저장된 active가 태오여도 새 학습 경험과 소풍은 재이에 연결된다. 다른 게임의 태오 카드는 변경하지 않았다. 공유 성장 JS/소풍 JS v2, SW v122.

로컬 구현. 공개 배포/push는 하지 않음. 기존 V49 원화·렌더러·코디 저장·앨범은 그대로 사용.

## 실제로 들어간 기능

- 모험보드의 아이 선택(재이/태오)과 `princess:growth:v1` 성장 기록 공유.
- 이번 업데이트 이후 정답부터 해당 아이의 경험에 반영. 수학/시계는 지혜, 영어는 말하기, 기타는 발견. 재시도 후 정답도 인정하고 오답·부모님 우회는 경험을 주지 않음.
- 아이별 누적 10문제마다 성장별 1개. 기존 10문제 게임 티켓·하루 100문제 자유 이용은 그대로 유지. 성장별은 소비하거나 날짜가 바뀌어 깎지 않음.
- 하루 답안 순번을 기록해 같은 정답을 중복 지급하지 않음. 과거 공용 학습 기록은 어느 아이 것인지 알 수 없으므로 소급 배분하지 않음.
- 공주가 현재 입은 옷으로 출발 → 사과 6개를 세 친구에게 2개씩 나누기 → 토끼 발자국 찾기 → “Come with me.” 뜻 고르기 → 토끼 친구·소풍 기념품·사진 일기.
- 지혜 3부터 나누기 도우미, 말하기 5부터 인사말 힌트. 공부 없이도 수동으로 모두 해결 가능. 도움 사용은 별도의 공부 실적으로 세지 않음.
- 진행 중 닫기/새로고침 후 이어하기. 아이별 친구와 첫 일기 분리. 반복 플레이로 친구·기념사진을 중복 지급하거나 덮어쓰지 않음.
- 첫 일기 사진은 420×680 JPEG. 저장 공간 오류 시 기존 진행을 유지하고 재시도 가능. 사진 생성 실패 시 사진 없는 일기 저장을 명시적으로 선택 가능.
- 공주 게임 카드가 자연스러운 착용 모드로 진입. `data-play-key="princess"`로 기존 놀이 횟수를 유지.
- SW v121, 성장·소풍 모듈/CSS v1. 카드 자산 v63, 공주 원화/렌더러 v49 유지.

## 범위와 한계

- **새 성장 기록과 일기만 아이별 분리.** 기존 수학 진도·오답노트·게임 티켓·코디는 기존 공용 구조 유지.
- 이 소풍의 영어는 뜻 고르기. 음성 인식 채점이나 새로운 녹음은 추가하지 않음. 기존 모험보드 영어 읽기/칭찬음성은 변경하지 않음.
- 아직 이야기 극장 완청 연동, 공주의 집, 직업, 왕국 지도는 없음. 이번 범위는 첫 소풍 한 편과 성장 연동 기반.
- 오프라인 브라우저 검사는 필요한 그림을 먼저 읽은 뒤 연결을 끊어 진행/사진 저장을 확인한 것. 물리 iPad Safari는 미검증.

## 검증

```text
node --test "princess/tests/*.test.js" "cards/tests/hub-*.test.js" cards/tests/pwa.test.js
node princess/tests/journey-smoke.cjs
node princess/tests/wardrobe-smoke.cjs
```

소풍 스모크: 390×844, 820×1180, 1180×820. 중간 저장/재시작, 잘못된 분배·길·영어 후 재시도, 오프라인 사진 저장, 아이별 일기 분리, 코디 불변. 390에서는 QuotaExceededError를 주입해 완료 버튼 재활성화·재시도와 진행 보존 확인.

대시보드 스모크: 아이 선택 → 기존 공주 놀이 횟수 표시 → 티켓 한 장 소비 → 자연 착용 모드 진입 → 선택 아이 공유 확인. 부모님 우회와 날짜 변경, 100문제까지의 티켓 규칙은 단위 회귀 검사로 고정.
