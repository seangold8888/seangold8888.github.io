# 초대장 나들이와 내 이야기책 · v38

## 첫 묶음

- 초대장 6통: 무지개 생일파티, 빗방울 티파티, 달빛 무도회, 숲속 동물 소풍, 바닷속 음악회, 눈꽃 잠옷 파티.
- 부탁은 한 가지뿐이며, 맞추지 않아도 '마음대로 놀러 가기'가 가능하다. 외모 점수, 순위, 일일 접속 제한, 기존 옷 잠금은 없다.
- 기존 공주/의상/배경 원화로 구성한 공통 나들이 무대. 꾸벅 인사, 반짝 포즈, 동물 친구 반응, 짧은 별빛 효과와 비·눈·거품 효과. 새 관절 동작/별도 포즈 원화를 만든 것은 아니다.
- 사진과 초대장을 한 페이지로 저장하는 내 이야기책. 최대 24장, 장소별 추억 스티커 6개. 사진을 지워도 스티커는 유지한다.

## 저장과 안전

- 새 키 princess:storybook:v1만 사용한다. princess:outfits, princess:album, 기존 공주 선택과 색 저장 형식은 그대로다.
- 나들이 의상은 깊은 복사본이다. 배경 변경 및 나들이에서 동물 부르기는 실제 옷장 저장을 바꾸지 않는다.
- 사진은 선택한 원화들을 내장한 SVG를 336×544 JPEG로 저장한다. 포즈와 날씨도 사진에 포함된다.
- 저장 중 중복 입력 방지, 페이지 ID 중복 방지, 닫힌 화면의 늦은 사진 저장 취소. 용량 초과/24장 만료 시 기존 사진을 자동 삭제하지 않는다.
- 사진 삭제는 명시적 확인 후 해당 이야기책 사진 한 장만 제거한다. 예전 앨범은 별도로 남는다.
- 이야기책 텍스트는 DOM textContent로 삽입하고, 저장 사진은 data:image/jpeg 또는 png만 읽는다.
- 모션 줄이기 설정을 존중하며 소리는 기존 공주옷장의 음소거 설정을 따른다.

## 연결

- index.html: 기존 꾸미기와 새 모듈 사이의 작은 어댑터. renderStage가 초대장 준비 상태를 갱신한다.
- outings.js / outings.css: 새 놀이. 기존 studio.js?v=36과 원화는 변경하지 않았다.
- 서비스 워커 v109에 outings.js?v=1, outings.css?v=1 추가. 공주옷장 직접 방문도 공유 서비스 워커를 등록한다. 카드 자산 v63은 그대로다.
- 배포는 아직 하지 않았다. 검수용 로컬 주소: /princess/?v=outing-v1
