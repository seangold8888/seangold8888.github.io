# 얼굴을 가리는 앞머리 수정

## 원인과 수정

v41에서 전체 머리 폭을 줄이면 원화의 얼굴 구멍도 함께 좁아졌다. 머리 외곽 크기를 다시 키우지 않고, 얼굴 앞 레이어에만 부드러운 얼굴 보호 마스크를 추가했다.

- 실제 인물별 관자놀이 좌표와 몸의 가로 이동값을 사용해 눈·볼·턱 부분을 드러낸다. 이마 위쪽과 뒤쪽 머리는 유지한다.
- 마스크는 바깥쪽 SVG 좌표계의 그룹에 적용한다. 각 머리 조각 SVG 내부에 적용하면 좌표계가 달라지므로 금지한다.
- 경계는 0.8 단위 블러로 부드럽게 이어진다. 앞머리의 접촉 그림자도 유지한다.
- 이미 승인된 단발에는 마스크를 적용하지 않는다. 모든 스타일의 외곽 크기·색·원화, 얼굴과 옷, 기존 저장 기록은 그대로다.
- 초상화·꾸미기·나들이·새 사진 모두 공용 렌더러로 반영된다. 기존 사진은 바꾸지 않는다.
- studio.js 쿼리 v42, 서비스워커 v113. 카드 자산 v63 및 아이콘 v1 유지.
