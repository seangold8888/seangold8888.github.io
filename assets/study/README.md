# Family study artwork

These five JPEG files were extracted byte-for-byte from the retired picnic/index.html. No generated replacements, cropping, or recompression were applied.

Use node tools/extract-study-art.cjs from the site root to reproduce them. The extractor reads the original committed HTML after the game is removed.

The hub uses these images only; the old picnic game, audio and separate learning system are not imported. Existing browser learning and collection records are not deleted.
