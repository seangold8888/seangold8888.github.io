# 영어 문장 읽기 — 칭찬 음성 + 틀린 단어 읽어주기 (스펙 v1)

> 작성: 클로드(기획) 2026-09-06 → 구현: 코덱스. 대상 파일 `assets/study/english-reading.js`, `index.html`(허브), `sw.js`.
> 사용자 확정 원칙: **읽기 연습이 목적. 「먼저 들어 보기」 버튼은 두지 않는다. 문장 전체를 모범 낭독해 주지도 않는다.** 아이가 먼저 읽고, 결과에 따라서만 소리가 난다.

## 1. 통과 시 — 텐션 높은 영어 칭찬 (음성 + 화면)

- 음성 파일: `assets/study/praise/*.mp3` 9개 (Gemini TTS, Leda, 일반 8개 1.06~1.65초, 3연속 3.06초, 총 70KB). 재생은 HTMLAudio. 외부 합성음(speechSynthesis)으로 칭찬하지 않는다 — 텐션이 안 산다.
- 단계:
  | 상황 | 후보 클립 | 화면 문구 |
  |---|---|---|
  | 첫 시도에 통과 | excellent, perfect, awesome, wonderful | 큰 글씨 `⭐ Excellent!` + 작은 한글 `한 번에 읽었어!` |
  | 다시 읽기 후 통과 | great, verygood, youdidit, super | `⭐ Great!` + `다시 읽어서 해냈어!` |
  | 첫 시도 통과 3연속 | threeinarow (전용) | `🌟 Three in a row!` + `세 문장 연속!` + 별 폭죽 |
- 같은 단계 안에서 무작위, 단 **직전 클립과 같은 것은 금지**(세션 메모리로 충분).
- 3연속 카운터는 세션 메모리만(localStorage 저장 안 함). 첫 시도 실패 또는 마이크 오류 시 0으로 리셋. 마이크 오류는 오답이 아니지만 연속 흐름은 끊긴 것으로 본다.
- 순서: 인식기 stop → 화면 문구/별 → 클립 재생 → 재생 끝 후 다음 문제. 일반 칭찬은 최대 1.8초, 총 연출 2초 이내. **3연속 전용 클립은 사용자 확정(2026-09-06)에 따라 길이 제한 없이 끝까지 재생한다**(현재 파일 3.06초). 재생 진행이 5초 동안 없으면 오류 복구로 넘어간다. 기존 통과 처리(`onPass` → `pick`)의 추가 대기는 없앤다.
- 클립 재생 실패(오프라인 캐시 누락, 자동재생 차단)는 조용히 무시. 화면 문구만으로도 성립해야 한다.

## 2. 실패 시 — 틀린 단어만 한 번 읽어주기

- 지금 `finishAttempt`가 빨간 표시하는 그 단어들(`retry` 플래그)을 **문장 순서대로, 최대 3개, 한 번만** 읽어준다. 문장 전체는 읽지 않는다.
- 음성: `speechSynthesis`, `lang = "en-US"`, `rate 0.8`, `pitch 1.0`. 단어 사이 0.4초 간격(utterance 분리). voice 선택: `en-US`이면서 `localService`인 것 우선(아이패드 Samantha). 영어 voice가 하나도 없으면 소리 없이 넘어간다(오류 문구 금지).
- 화면 문구: `"이렇게 읽어요 👂 apples"` — 현재 "문장이 다르게 들렸어요…" 문구를 이 형태로 바꾼다. **"틀렸어요"라는 말은 쓰지 않는다**(인식기 오류인 경우가 많다).
- 읽어주는 동안 빨간 단어를 하나씩 순서대로 노란 하이라이트(듣는 단어 = 보는 단어).
- 예외: `wholeLine`(단어는 다 있는데 딴 말이 섞임)일 때는 아무 단어도 읽어주지 않고 `"문장에 있는 말만 읽어 주세요"`만 표시.
- 재생이 끝나야 `🎤 다시 읽기` 활성. 재생 중 탭하면 speechSynthesis.cancel() 후 바로 녹음 시작.

## 3. 기술 주의 (필수)

1. 소리 내기 전에 인식기 반드시 `stop()`. 소리 끝난 뒤 **자동 재시작 금지** — 스피커 소리를 마이크가 주워서 오답 처리되는 사고 방지. 아이가 버튼을 다시 눌러야 한다.
2. iOS Safari는 사용자 탭 안에서 첫 재생을 풀어야 한다: `🎤 읽어 보기` 탭 핸들러에서 `speechSynthesis.speak(new SpeechSynthesisUtterance(""))` 1회 + praise Audio 객체 `load()` 1회. 이후 비동기 재생 허용됨.
3. `visibilitychange`(숨김) 시 speechSynthesis.cancel(), 클립 pause.
4. 캐시: `english-reading.js?v=4`, `sw.js` CACHE_VERSION +1, praise mp3 9개 CORE_SHELL 프리캐시(오프라인 칭찬 유지).
5. 복습 기록(`readingMistake`)·오답 규칙·마이크 오류 처리는 지금 그대로. 이 스펙은 소리와 문구만 바꾼다.

## 4. 테스트 (cards/tests/hub-english-feedback.test.js 신설)

- 단계 매핑: 첫 시도 통과 → 1군 클립, 재시도 후 통과 → 2군, 3연속 → threeinarow. 실패·마이크 오류로 연속 0 리셋.
- 직전 클립 반복 없음(100회 난수 돌려 검증).
- 틀린 단어 낭독 목록: 문장 순서, 중복 제거, 최대 3개, wholeLine이면 빈 목록.
- speak 호출 전 recognizer.stop 호출됨(호출 순서 스파이).
- 영어 voice 없음 → speak 미호출, 오류 문구 없음.
- `?v=4` + CACHE_VERSION 핀(기존 pwa 테스트 패턴).
