# 영어 그림책 (/story/english/)

2026-09-19 사용자 요청: "스토리북도 영어 컨텐츠 만들어보자".

- 6권 × 8쪽. 쉬운 책부터: 재이와 태오의 소풍(★) · 아기돼지 삼형제(★) · 토끼와 거북(★★) · 빨간 모자(★★) · 잭과 콩나무(★★★) · 신데렐라(★★★).
- 본문과 한글 뜻은 `books.js`. 쪽마다 전용 삽화 `art/<책>-<쪽>.webp`(gemini-3-pro-image, 카드 원화를 참고 이미지로 넣어 인물 유지, 1024px webp). 파일이 없으면 카드 원화로 대신한다.
- 쪽마다 🔊 들어 보기(낭독 mp3, Gemini TTS Leda), 한글 뜻 보기(처음엔 숨김), 🎤 내가 읽기(모험 상자 영어 읽기 기능을 그대로 사용, 맞게 읽으면 다음 쪽).
- 낭독 파일: `audio/<책 id>-<쪽>.mp3`. 오프라인은 서비스 워커의 mp3 처리 규칙으로 요청 시 저장된다. 화면·책 데이터는 CORE_SHELL.
- 다 읽은 책은 기기에 `story_english_done`으로 기억하고 책장에 "다 읽었어요 ⭐"를 붙인다.
- 티켓 없이 들어가는 곳이라 게임 시간 제한(play-timer)을 싣지 않는다.
- 이름(Jaei, Taeo)은 음성 인식이 잘 못 알아들을 수 있어 허용어(jay, tao, teo 등)를 넣었다. 그래도 틀리면 다음 쪽 버튼으로 넘어갈 수 있다.
- 점검: `node tools/english-books-smoke.cjs`
- 신데렐라 5쪽은 금발·파란 드레스로 나와 다른 쪽(갈색 곱슬머리·분홍 드레스)과 다르다. 09-19 다시 그리려 했으나 API 선불 크레딧 소진으로 보류. 7쪽은 사람 없이 유리 구두만 그렸다(왕자+유리 구두 장면이 계속 정책 거절).
