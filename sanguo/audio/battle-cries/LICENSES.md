# Battle cry audio licenses

All files in this directory are used as short non-verbal combat calls. The game
keeps the original downloaded audio bytes and only applies realtime gain, EQ,
playback-rate and reverb settings in the Web Audio graph.

## Male battle cries

- Source: [Male Grunt/Yelling sounds](https://opengameart.org/content/male-gruntyelling-sounds)
- Creator: HaelDB
- License: [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)
- Local files: `male-noble-a-cc0.wav`, `male-noble-b-cc0.wav`,
  `male-fierce-a-cc0.wav`, `male-fierce-b-cc0.wav`,
  `male-heavy-a-cc0.wav`, `male-heavy-b-cc0.wav`,
  `male-agile-a-cc0.wav`, `male-agile-b-cc0.wav`

## Female battle cries

- Source: [Female Warrior Cheer](https://opengameart.org/content/female-warrior-cheer)
- Creator: SkyRae
- License: [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)
- Local file: `female-warrior-cheers-cc0.mp3`
- Playback regions: 0.33–1.46 s, 1.67–2.80 s and 3.13–4.02 s. The longer
  fourth take remains in the source file but is not used in combat.

Source pages and license status were checked on 2026-09-09.
