# 재이의 수학놀이터 — DESIGN.md

> 재이가 가장 좋아하는 구름사다리에서 시작하는, 매일 만나고 싶은 수학놀이터.

버전 2.1 · 2026-09-08 · v23 화면 구현 기준. 모든 아이 화면과 부모 화면에 적용한다.

## 1. 목적과 콘셉트

공식 이름은 **재이의 수학놀이터**다. 제목·부모 화면·인쇄물에서 같은 이름을 쓴다.

밝은 낮의 동네 놀이터, 칠한 나무 장난감, 부드러운 모래 바닥과 하늘색·망고색·코랄색 놀이기구가 기준이다. 가장 큰 놀이기구는 구름사다리이며 기본 선택도 구름사다리다. 밤하늘·꽃밭·씨앗 심기·정원 가꾸기 표현을 제품 화면에 사용하지 않는다.

핵심 경험은 ‘문제 하나, 구름사다리 한 칸’이다. 수학을 해결하면 진행 칸과 탐험 도장이 쌓인다. 오답으로 떨어지거나 처음으로 돌아가지 않는다. 빨리 풀기보다 생각하기·도움받기·다시 해보기·쉬기를 지원한다.

시선 순서는 현재 할 일 → 시작 버튼 또는 문제 → 도움 → 보상과 기록이다. 홈과 결과는 그림으로 초대하고 문제는 차분한 밝은 면에 집중한다. 자유롭게 고르는 놀이기구는 학습 난이도나 숙달 조건을 바꾸지 않는다.

## 4. 글자·간격·표면 규칙

- 아이 제목·짧은 안내: Jua 400, Apple SD Gothic Neo, Malgun Gothic, system-ui 순서.
- 계산식·키패드·숫자: Nunito 800/900, Jua, system-ui. 숫자는 tabular-nums.
- 부모 카드·폼: 시스템 한국어 sans-serif, 행간 1.6.
- 브랜드 23px / 모바일 19px. 홈 제목 32px / 700px 이하 27px.
- 미션 25px / 모바일 22px. 식 40px / 모바일 34px. 키패드 29px.
- 주 안내는 16px 이상을 우선하고 작은 캡션에 핵심 지시를 숨기지 않는다.
- 홈 최대 폭 920px, 집중 화면 620px, 부모 화면 1000px.
- 페이지 좌우 여백 24px / 모바일 14px. 카드 패딩 22px / 모바일 18px.
- 카드 반경 22px, 홈 장면 30px / 모바일 24px, 버튼 15px, 입력 12px.
- 일반 카드 그림자 `0 8px 30px #244f6409`, 장면 그림자 `0 14px 35px #244f6418`.
- 주 버튼 받침 4px. 누를 때 3px 내려가고 받침은 1px로 줄어든다.
- 새 간격은 4·8·12·16·24·32·40px 계열을 우선하되 명시된 기존 컴포넌트 치수는 유지한다.

## 5. 컴포넌트와 상태

| 컴포넌트 | 기본 및 반응 |
|---|---|
| 주 버튼 | 청록색·흰 글자·단단한 받침. 한 화면의 핵심 행동 하나 |
| 보조 버튼 | 옅은 청록 면. 가볍게 3문제·옷장·도움 이동 |
| 놀이기구 선택 | SVG 아이콘과 한글 이름. 구름사다리에는 ‘최애’ 배지. 선택 테두리와 aria-pressed. 모두 자유 선택 |
| 탐험 사다리 | 문제 수만큼 칸 표시. 완료는 코랄과 체크, 현재는 망고와 외곽선. 오답에는 칸을 빼지 않음 |
| 키패드 | 숫자는 동일한 밝은 면, 확인은 청록색. 숫자 배치 고정 |
| 답칸 | 선명한 아래 경계. 성공·도움 문구와 색을 함께 표시 |
| 블록 힌트 | 주어진 블록은 파랑이며 고정. 추가 블록은 코랄이며 다시 눌러 취소. 빈 칸은 점선, 상태는 aria-pressed로 전달 |
| 도움 버튼 | 베이지색 pill, 힌트 → 그림 → 풀이 예시 → 재시도 |
| 친구·옷장 | 현재 친구·코인·가격·소유 상태를 함께 표시. 기존 수집 자료 유지 |
| 개념 기록 | 아직 안 함 / 연습 중 / 다른 날에도 해결. 확인된 기록만 표시 |
| 보상 | 실제 탐험 도장·코인·스티커. 한 번의 완료에 한 번 반영 |

키보드 포커스는 3px, offset 4px다. 주 버튼·키패드·놀이기구·블록·색상 선택의 누름 영역은 44px 이상으로 유지한다. 비활성 요소는 실제 disabled와 시각 상태를 함께 적용한다. 핵심 피드백은 기존 role=status와 aria-live=polite를 유지한다. 접근성 대비·전체 요소의 누름 영역은 지속 점검 목표이며 전면 인증을 의미하지 않는다.

## 6. 화면과 반응형

- 첫 방문: 구름사다리 장면과 3문제 체험. 이름 선택, 진단도 선택 가능.
- 홈: 장면 → 시작/이어하기 → 놀이기구 선택 → 친구·기록. 390×844에서 시작 버튼이 첫 화면에 보이게 한다.
- 문제: 작은 사다리 진행 표시 → 문제·도움·키패드. 큰 배경 그림을 수식 뒤에 넣지 않는다.
- 복귀: 이미 해결한 문제와 도움 사용 여부를 유지하고 하던 탐험을 이어간다.
- 결과·칭찬: 실제 해결한 문제·도장·코인을 축하하고 끝내기 버튼을 제공한다.
- 부모: 같은 팔레트에 낮은 장식 밀도. 표를 읽고 복사할 수 있다. 인쇄 시 장식은 숨긴다.
- 700px 이하: 제목 다음에 원본 비율 그림을 배치하는 단일 열, 놀이기구 3열. 701px 이상은 제목과 그림을 나란히 배치하며 놀이기구 6열.
- 홈 그림은 width 100%, height auto로 원본 3:2 비율을 유지한다. 고정 높이·cover·패널 겹침으로 잘라내지 않는다. 환영·결과 그림도 object-fit: contain으로 전체를 표시한다.
- 안전 영역 inset을 페이지 여백에 반영하고 터치 화면에서는 놀이기구 hover 이동을 끈다.
- 760px 이상: 홈 캐릭터와 길잡이 2열. 문제는 최대 620px이되 900px 이상 가로 화면에서는 최대 1000px의 문제·숫자판 2열로 전환한다. 숫자 버튼 높이는 64px. 좁아지거나 세로로 회전하면 한 열로 복귀한다.
- 320px에서 페이지 가로 넘침을 허용하지 않는다. 표·옷장 탭·배움 지도만 필요한 범위에서 가로 스크롤한다.
- 글자 확대와 긴 이름으로 공간이 부족하면 줄바꿈한다. 확대를 막거나 필수 문구를 자르지 않는다.

## 7. 그림과 움직임

장면 파일은 `assets/playground-monkey-bars.webp`(1536×1024)다. 최종 생성 프롬프트와 출처는 `assets/playground-art.md`에 기록한다. 가장 크게 보이는 파란 프레임·코랄 가로봉·노란 기둥의 구름사다리가 기준이다. 모바일·아이패드·데스크톱 모두 원본 그림의 전체 범위를 보여야 한다.

장면은 홈·환영·결과에 재사용한다. 숫자·수식·버튼은 HTML이며 이미지가 로드되지 않아도 시작할 수 있다. 놀이기구 아이콘은 `playground.js`의 자체 SVG다. 기존 캐릭터 옷·앨범 수집 그림은 그대로 사용한다.

장식의 지속 흔들림은 끈다. 놀이기구 hover와 진행 상태는 약 150ms. reduced-motion에서는 애니메이션·전환·부드러운 스크롤을 끈다. 수학 피드백을 읽는 동안 화면을 흔들지 않는다.

## 8. 작업과 검증

1. README의 저장·숙달·보상 규칙을 읽는다. 시각 변경으로 기록을 초기화하거나 난이도를 바꾸지 않는다.
2. style.css와 playground.css의 선택자 우선순위를 함께 확인한다.
3. 공통 버튼·카드·폼·키패드를 재사용하고 변경한 토큰을 이 문서에도 반영한다.
4. 홈·문제·힌트·오답·결과·옷장·부모 화면을 확인한다.
5. 기록을 건드렸다면 이전 저장 데이터, 새로고침, 이어하기를 검사한다.
6. browser-smoke.cjs로 실제 학습 흐름, browser-responsive.cjs로 아이패드 가로·세로·분할 화면 및 PC를 검사한다. 화면 회전 시 문제·도움 기록 유지, 그림 비율, 터치 목표, 가로 넘침과 시작 버튼 위치를 확인한다. 변경된 CSS·JS 캐시 버전을 갱신한다.

반응형 검증은 Chromium 터치 에뮬레이션 기준이며 실제 iPad 하드웨어와 Safari 검증은 포함하지 않는다.

검증 범위 밖의 항목: 모든 화면의 WCAG 전면 감사, 실제 아동을 대상으로 한 장기 학습 효과 검증. 개선 시 실제 사용 관찰을 근거로 판단하며 재미나 학습 향상을 수치로 보장하지 않는다.
