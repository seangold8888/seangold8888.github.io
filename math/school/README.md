# 학교 유형 연습

questions.js: 사진의 20개 문항 형식을 각각 변형하는 결정적 문제 생성기. 숫자 묶음, 그림 세기, 수와 읽는 말 연결, 다른 수 찾기, 묶음 크기, 포장 문제, 묶음과 낱개, 수 읽기, 앞뒤 수, 연속 수, 100의 뜻, 어떤 수, 가능한 숫자 개수, 숫자 카드 최댓값, 부등호, 생활 비교, 홀수 일의 자리, 짝수 복수 선택, 짝/홀 분류, 홀수 묶음.

school.js: 학교 연습만 저장하는 독립 UI. 객관식/복수 선택/숫자 빈칸/연결용 선택상자/선택적 서술형 메모. 서술형은 예시 풀이와 비교하며 자동 채점하지 않는다. 기존 학습 숙달·단계·코인·파티·티켓을 수정하지 않는다.

기본 5문제, 유형별 선택(짝홀은 4종), 전체 20문제. 힌트, 풀이 보기, 쉬었다 이어하기, 일찍 마치기, 최근 풀이 다시 보기. 최근 회차 상세 및 최대 30회 요약을 math10_school_v1에 저장한다. 학습 효과나 학교 성적을 추정하는 기능은 없다.


## 주간 시험

weekly.html / weekly.js / weekly-engine.js는 금요일부터 주당 한 번(요일 변경 가능) 진도 시험을 제공합니다. 학교에서 만나본 유형/부모 수동 진도/놀이터 현재 단계의 세 가지 범위를 지원합니다. 문제 스냅샷과 답을 고정 보관하고 제출 후 채점하며, 기존 연습과 저장 키를 분리합니다. 자세한 주간 경계, 미완료 이월, 점수 및 저장 규칙은 상위 README를 참고하세요. view.js는 연습과 시험의 공통 답 입력·문제 그림입니다.
