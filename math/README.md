# 매일 수학 10분 (`/math/`)

재이용 수 감각·연산 연습 사이트. 게임 허브와 분리된 독립 페이지(허브에서 링크하지 않음). 로그인 없음, 기록은 기기 브라우저에만.

- `index.html` 아이 화면 — 12문제 세션, 십틀·수 모형 그림, 숫자 키패드(찍기 불가), 틀리면 정답+그림 보고 같은 문제 다시.
- `parent.html` 부모님 — 단계별 정확도·중간 시간·안정도, 복습 대기, 설정(단계·문제 수·그림·소리), 종이 문제지 인쇄, 기록 내보내기.
- `curriculum.js` 11단계(1-1 모으기·가르기 → 2-1 받아내림 두 자리) 문제 생성 · `visual.js` 그림 · `store.js` 저장·간격 반복(1→3→7→14일)·승급(90% 2회)/강등(60%).
- 테스트: `node --test "math/tests/*.test.js"` (site 루트에서).
- 원칙: 아이에게 시간·점수 안 보임, "틀렸어" 문구 없음, 정답 확인 후 재시도 필수, 숫자는 그림에 넣지 않음.
