# 재이의 수학놀이터 (`/math/`)

구름사다리를 가장 좋아하는 재이를 위한 놀이터 테마 수학 학습. 기존 GitHub Pages 주소와 기기별 `math10_state` 저장 키를 유지한다.

화면 수정 전 [DESIGN.md](DESIGN.md)를 먼저 읽는다. 색상·타이포그래피·간격·상태·반응형 규칙과 현재 구현의 정비 목록을 담고 있다.

## 학습 흐름

- 첫 방문: 이름은 선택, 3문제 체험 또는 기존 실력 확인 선택. 학교 입력은 부모 화면에 있다.
- 홈: 오늘의 모험(기존 8/12/16문제 설정 유지), 짧은 3문제, 중단한 모험 이어하기.
- 도움: 전략 힌트 → 그림/놓고 빼는 블록 모형 → 풀이 예시 → 직접 재시도. 도움을 쓴 문제는 독립 정답으로 기록하지 않는다.
- 일반 모험은 도움을 쓴 뒤 같은 개념의 새 문제를 최대 1개 추가해 다시 확인한다. 짧은 모험은 3문제로 끝난다.
- 오답 복습은 같은 유형의 새로운 예시로 출제하고 원래 복습 항목의 1→3→7→14일 간격을 갱신한다.
- 모든 문제 해결에 1코인, 하루 첫 완료 10코인. 어려웠던 개념을 독립 해결하면 유형별 하루 한 번 2코인. 완벽 정답 보너스는 사용하지 않는다.
- 해결한 문제 수가 탐험 도장으로 쌓인다. 기존 캡슐·친구 앨범·옷장·칭찬 도장을 유지하며 선물 목표를 직접 선택할 수 있다.

## 놀이터 경험

- 구름사다리가 기본 선택이다. 미끄럼틀·그네·시소·블록놀이·징검다리도 자유롭게 선택한다. 선택은 `playgroundSpot`에 저장하며 학습 난이도를 바꾸지 않는다.
- 문제를 해결하면 진행 사다리의 한 칸이 채워진다. 틀려도 완료한 칸은 줄지 않는다. 중단 후에도 이어갈 수 있다.
- 신규 선택·아이콘은 `playground.js`에 모은다. 그림 제작 프롬프트는 `assets/playground-art.md`에 기록한다.
- 기존 누적 발견 수는 호환성을 위해 내부 `garden` 필드에 보관하며 화면에서는 탐험 도장으로 표시한다.

- 홈 진도는 중단한 탐험이 있으면 그 문제 수·해결 수, 없으면 오늘 마지막 완료한 탐험, 오늘 완료 기록도 없으면 다음 일반 탐험 0문제를 표시한다. 서로 다른 지표를 혼합하지 않는다.
- 12칸 배움 사다리는 현재 단계와 실제 숙달 기록을 분리한다. 시작 단계 이전을 자동 숙달로 간주하지 않는다.
- 왼쪽부터 아빠–태오–재이(여자아이)–엄마 순서의 가족 네 명과 폼폼푸린·헬로키티를 입체풍 캐릭터로 홈·진도·결과에 표시한다. 최종 프롬프트는 `assets/jaei-characters-art.md`에 기록한다.

## 숙달과 기록

`learning.js`가 개념별 기록, 약한 유형 우선 출제, 힌트와 변형 문제를 담당한다. 현재 단계의 모든 유형이 아래 조건을 만족하면 승급한다.

- 최근 최대 6개 기록 중 독립 정답 비율 80% 이상
- 기록 최소 4개, 서로 다른 정답 문제 최소 3개
- 독립 정답을 낸 날짜 최소 2일

같은 날 같은 문제를 반복해도 기록 수가 늘지 않는다. 그날 도움을 쓴 사실도 지워지지 않는다. 계획 날짜는 승급 기준이나 상한에 영향을 주지 않으며 자동 강등은 없다. 기존 기록으로 새 개념 숙달을 추정하지 않는다. 워밍업은 현재 단계 정확도에서 제외한다. 손가락 사용·자동화 여부를 반응시간만으로 단정하지 않는다.

현재 범위는 수 감각·덧셈·뺄셈 12단계이며 도형·측정 전체 교육과정을 대체하지 않는다.

## 파일과 확인

- `index.html`, `app.js`: 아이 화면, 이어하기, 보상, 놀이터
- `playground.css`, `assets/playground-scene.webp`: 새 시각 디자인 (기존 CSS 위에 적용)
- `learning.js`, `store.js`: 학습 규칙 및 이전 데이터 보존
- `parent.html`, `parent.js`: 유형별 기록과 부모용 놀이 제안
- `node --test math/tests/*.test.js`: 순수 모듈 회귀 테스트
- `node math/tests/browser-smoke.cjs`: 별도 임시 브라우저에서 전체 학습 흐름 및 모바일 화면 확인. Playwright 경로는 `PLAYWRIGHT_PATH`로 지정 가능. `TEST_BASE`는 공개 사이트 검증용.

- `node math/tests/browser-responsive.cjs`: 아이패드 가로·세로·분할 화면, 휴대폰, 데스크톱 9개 화면의 전체 그림 표시·터치·회전·이어하기 확인. Chromium 터치 에뮬레이션이며 실기기 Safari 검증은 별도다.

로그인 없이 이 기기의 브라우저에만 저장한다. 내보내기·가져오기는 부모 화면에 있다. 메인 화면 CSS와 app.js는 v28 URL로 갱신되며 기존 서비스 워커의 HTML/JS/CSS 네트워크 우선 정책을 따른다.


## 생일파티 모험

party/에 4단계(10 모으기·가르기와 10 만들기) 기반의 짧은 조작 놀이를 추가했습니다. 모험보드와 놀이터의 초대 링크에서 티켓 없이 입장하며, 불빛·쿠키·풍선 준비 후 가족 파티를 자유롭게 즐깁니다. 기존 수학 단계는 변경하지 않습니다.

진행 상태는 별도 math10_party_v1 키로 저장합니다. 부모님 화면의 파티 카드에서 조작 연습 기록을 볼 수 있으며, 독립 숙달이나 기존 정답·코인에 합산하지 않습니다. 기존 백업과 초기화는 수학놀이터 기록에만 적용됩니다. 자세한 동작과 검증은 party/README.md를 참고하세요.


## 학교 시험 유형 연습

school/은 학교 시험 사진의 ‘100까지의 수’ 형식 20종을 숫자와 상황을 바꾸어 출제합니다. 원본 사진·학교명·학생 개인정보는 사이트에 포함하지 않습니다. 기본 5문제와 전체 20문제, 묶음·수 읽기 / 순서·비교 / 짝수·홀수 유형별 연습을 지원합니다. 기존 4단계 파티나 연산 진도를 대체하지 않습니다.

학교 연습은 math10_school_v1에만 저장합니다. 입력 중인 답과 서술형 메모, 다시 시도, 힌트·풀이 열람, 진행 위치를 유지합니다. 정답을 확인한 뒤 새로고침해도 기록이 중복되지 않습니다. 최근 완료/일찍 마친 회차 요약은 30회, 가장 최근 회차의 상세 답·풀이를 보관합니다. ‘도움 없이 해결’은 해당 연습에서 힌트·풀이를 보지 않고 정답을 낸 문항이며, 독립 숙달이나 승급을 뜻하지 않습니다. 서술형 답안 문장은 자동 채점하지 않습니다.

부모님 화면은 별도 학교 연습 요약과 바로가기를 제공합니다. 기존 내보내기·초기화는 수학놀이터 학습 기록만 대상으로 하며 학교 연습은 포함하지 않습니다. 저장 실패는 안내하고 현재 화면에서 계속 풀 수 있습니다.

검증: node --test math/tests/school.test.js 및 node math/tests/browser-school.cjs. 생성 문제의 정답·선택지 고유성·그림의 수량·복수 선택 채점과 20종 실제 풀이, 이어하기, 기록 분리, 320px 및 iPad 크기를 확인합니다. 브라우저 검증은 Chromium 터치 에뮬레이션입니다.


## 일주일에 한 번 · 진도 시험

school/weekly.html에 주간 시험을 제공합니다. 기본 금요일·최대 10문제이며 부모님이 요일, 최대 5/10/20문항, 진도 기준을 바꿀 수 있습니다. 날짜는 기기 현지 시간 기준이며 월요일~일요일을 한 주로 계산합니다. 선택 요일부터 해당 주 일요일까지 시작할 수 있고 주당 한 시험만 생성합니다. 이전 주에 시작한 미제출 시험은 먼저 이어서 풀며, 제출하면 이번 주 시험 가능 여부를 다시 판단합니다. 응시하지 않은 지난 주 시험을 뒤늦게 새로 만들지는 않습니다. 알림·백그라운드 예약 작업은 없으며 사이트를 열거나 다시 포커스할 때 날짜를 확인합니다.

진도 기준은 (1) 학교 유형 연습에서 만나본 유형 자동, (2) 부모님이 배운 학교 유형 직접 선택, (3) 놀이터 현재 단계와 직전 단계 복습입니다. 날짜별 계획만으로 진도를 앞당기지 않습니다. 학교 연습은 앞으로 완료/풀이 열람한 유형을 covered에 누적합니다. 이전 버전 기록은 남아 있는 최근 회차의 유형만 읽으며, 과거 회차의 ‘골고루’ 같은 요약으로 모든 유형을 배웠다고 추정하지 않습니다. 만나본 유형은 숙달을 뜻하지 않습니다. 아직 범위가 없으면 설정 또는 연습을 안내합니다.

시작할 때 문제·범위·정답·풀이를 시험 스냅샷으로 저장합니다. 이미 시작한 시험은 부모 설정과 현재 진도가 바뀌어도 유지됩니다. 범위 내 문항이 부족하면 중복 문항을 늘리는 대신 문제 수를 줄입니다. 제출 전에는 정답·힌트·풀이를 화면에 표시하지 않고 자유롭게 문항 이동, 답 수정, 쉬었다 이어하기를 지원합니다. 제출 확인 화면은 미응답을 표시하며 미응답 포함 최종 제출도 가능합니다. 제출 후에는 수정/재응시 없이 점수·유형별 결과·내 답·예시 풀이를 확인합니다. 서술형 문장은 자동 채점에 포함하지 않습니다. 문항별 동일 배점, 복수 정답/여러 칸은 모두 일치해야 정답입니다.

math10_weekly_v1에 최근 52회 시험 전체를 저장하며 기존 학습·코인·숙달·파티·학교 연습을 수정하지 않습니다. 일주일에 한 번 제한은 해당 브라우저 저장소 기준이고 기기 간 자동 동기화는 없습니다. 부모님의 기존 학습 기록 초기화/백업에는 주간 시험이 포함되지 않습니다. 저장 실패 시 안내하고 현재 열린 화면에서는 메모리로 계속 진행합니다. 학습 기록 보호를 위한 기능이며 서버 기반 시험 보안이나 부정행위 방지 기능은 아닙니다.

검증: weekly.test.js가 주/연도 경계·설정 요일·미완료 이월·주당 한 번·진도 스냅샷·채점/잠금·저장 분리를 확인하고, browser-weekly.cjs가 부모 설정·모든 입력 형태·답 수정/재개·미응답 제출·결과·부모 화면 및 iPad/320px 화면을 검증합니다.


## 간결한 메인 화면 (v28)

시작 버튼과 구름사다리 진도 아래에 가족 파티·학교 유형 연습·주간 시험을 같은 크기의 바로가기로 표시한다. 놀이기구는 ‘놀이기구 바꾸기’, 가족 그림·코인·숙달 지도·앨범·보물상자는 ‘내 기록과 친구들’을 펼쳐 이용한다. 옷장과 부모님 화면 링크는 접지 않는다. 기존 학습 규칙, 저장 키와 내용, 시험 일정은 변경하지 않는다. 작은 화면에서도 시작 버튼을 그림보다 먼저 보여 주며 놀이터 그림의 전체 비율을 유지한다.
