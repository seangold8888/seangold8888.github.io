# 가족 생일파티 모험

모험보드의 티켓 없는 바로가기와 수학놀이터에서 입장하는 짧은 4단계 조작 놀이입니다. 기존 학습지를 계속 풀기 싫어하는 재이를 위한 첫 시범 모험이며, 실제 재미와 학습 효과는 아이가 사용한 뒤 확인해야 합니다.

- 복숭아빛·하늘빛·초록빛 파티를 먼저 선택합니다.
- 불빛: 기존 4단계 make10 문제를 바탕으로 1·2·3개 묶음의 전기를 추가해 전구 열 개를 켭니다.
- 선물: from10의 열 개 쿠키 중 지정된 수를 상자로 옮깁니다. 옮긴 쿠키는 다시 누르면 돌아오며 남은 수가 함께 보입니다.
- 풍선: split10에 해당하는 합이 10인 세 쌍을 찾습니다. 실패해도 이미 연결한 풍선은 유지합니다.
- 완성 후 촛불 끄기, 케이크 선택, 가족 춤, 풍선 띄우기·터뜨리기를 자유롭게 즐깁니다. 추가 문제나 티켓 없이 재방문할 수 있습니다.

## 기록과 접근성

math10_party_v1에 파티 상태, 테마, 케이크, 도움 사용, 다시 시도, 최근 30개 활동을 저장합니다. 각 조작 직후 저장하며 다음 준비로 넘어가기 전에도 완료 여부를 유지합니다. 저장 실패 시 화면에 안내하고 현 세션은 계속 진행합니다.

math10_state, hub2_*는 읽거나 쓰지 않습니다. 활동은 mode: manipulative로 분류하며 정답률·독립 숙달·승급·코인·티켓에 반영하지 않습니다. 부모님 화면의 별도 카드에서 현재 준비와 최근 활동을 확인합니다. 기존 학습 기록 백업/초기화에는 이 별도 파티 기록이 포함되지 않습니다.

버튼은 48px 이상, 링크는 44px 이상이며 탭과 키보드로 조작합니다. 음악은 기본 꺼짐이며 켠 뒤에만 Web Audio 생일 왈츠와 효과음을 재생합니다. 마이크를 사용하지 않습니다. 움직임 줄이기 설정을 존중합니다. 가족 그림은 원본 비율로 표시합니다.

## 공주파티 살롱과 생일 음악 (2026-09-16)

### 재입장 초기화 (최신 동작)

춤 v2: 원화의 몸을 줄 단위로 휘게 하던 효과와 타원 공중 이동은 제거했다. 현재는 원본 비율을 유지한 작은 기울기와 반원 대형의 옆걸음 표현이다. 얼음 단계에서는 마지막 위치를 유지한다. 기존의 허리 변형·타원 회전 설명을 대체한다. 정면 원화만 사용한 제한적인 움직임이며 실제 관절 춤은 전용 자세 원화가 필요한 후속 작업이다.

매 입장·새로고침·브라우저 뒤로가기로 복귀할 때 준비 상태와 완료 표시, 촛불·왕관 도장을 초기화한다. ‘새 파티 준비하기’도 같은 초기화를 수행한다. 이전 이어하기/도장 영구 저장 설명보다 이 규칙이 우선한다. 부모 화면용 활동 이력은 유지하며 수학 숙달·티켓은 변경하지 않는다. 도장은 이번 방문에서만 표시한다.

완료 화면에서 ‘엉덩이 씰룩춤’과 ‘둥글게 둥글게’를 선택하면 가족 네 명의 전용 춤 무대가 열립니다. 기존 원화를 Canvas에서 사람별로 표시하며 씰룩춤은 얼굴·발보다 허리의 좌우 움직임을 크게 합니다. 둥글게 놀이는 타원 무대를 9초간 돌고 3초간 얼음 자세로 멈춥니다. 총 12초 후 자동 종료하며 다시 추기·박수·닫기·Escape를 지원합니다. 숨김/이탈 시 중단하며 움직임 줄이기는 정지 그림으로 대체합니다. 노래 ‘둥글게 둥글게’의 녹음이나 멜로디는 포함하지 않고, 켜 둔 생일 왈츠와 함께 노는 동작 놀이입니다.

기존 준비 세 단계를 마치면 선택형 살롱이 열립니다. 촛불 3·5·7개를 직접 더하고 빼며 세는 놀이, 별·하트·꽃의 반복 규칙을 찾는 왕관 놀이를 각각 세 번 즐깁니다. 틀려도 현재 단계를 유지하고 다시 고릅니다. 각 놀이 완료 도장은 `math10_party_badges_v1`에만 저장하며 진행 중인 소단계는 새로고침 시 처음부터입니다. 기존 파티 기록·수학 숙달·게임 티켓에는 영향이 없습니다.

‘음악 켜기’로 108BPM의 새로 만든 무가사 생일 왈츠를 반복 재생합니다. 알려진 생일 노래 녹음이 아닌 합성 멜로디·저음·화음입니다. 켜짐 상태를 저장하거나 자동 재생하지 않습니다. 탭 숨김·페이지 이동·링크 클릭 시 예약을 취소하고 AudioContext를 닫습니다. 돌아왔을 때는 다시 눌러야 합니다. 이는 오디오 자원 정리이며 iPad 음성인식 복구를 보증하지 않습니다.

검증: `node --test math/tests/party-music.test.js`, `node math/tests/browser-party.cjs`. 실제 iPad Safari의 음악 재생과 이후 영어읽기는 별도 기기 검증이 필요합니다.

## 검증

- node --test math/tests/party.test.js
- node math/tests/browser-party.cjs
- 기존 수학 단위 테스트와 browser-smoke.cjs, browser-responsive.cjs
- 브라우저 검증은 Chromium의 iPad 크기·터치 에뮬레이션이며 실제 iPad Safari 검증은 별도로 필요합니다.


## 짝수·홀수 설명 놀이 (2026-09-09)

첫 초대, 쿠키 선물 만들기, 완성한 파티의 ‘쿠키 짝꿍 놀이’ 버튼에서 선택적으로 열 수 있습니다. 두 개씩 짝지어 남는 것이 없으면 짝수, 한 개가 남으면 홀수라는 설명과 4·5의 비교 예시를 제공합니다. 쿠키 0~10개를 선택하고 한 번에 한 쌍씩 묶어 눈으로 확인합니다. 0은 남는 것이 없어 짝수임을 별도로 설명합니다.

기존 쿠키 재질과 파티 버튼을 재사용하며, 만든 쌍은 묶음 테두리, 남은 한 개는 점선 테두리와 문장으로 구분합니다. 대화상자는 작은 화면에서 내부 스크롤하며 닫기·Escape와 원래 버튼으로의 포커스 복귀를 지원합니다. 연습은 추가 필수 단계가 아니며 저장 기록·파티 완료·독립 숙달에 영향을 주지 않습니다. browser-party.cjs가 0~10 전체의 개수 보존·판정, 320px 및 iPad 화면, 진행 보존을 검증합니다.
