# 오행 상성 — 전투 규칙

2026-09-09: 기존 분류의 약점 ×2를 오행 추가 피해 +10으로 대체한다.

공격 우위: 나무 → 땅 → 물 → 불 → 금속 → 나무.
그 밖의 조합은 기본 피해 그대로다. 역방향 피해 감소는 없다.
0 피해 기술에는 추가 피해가 없고, 이야기 필살기는 기존 중립 피해를 유지한다.
페르세우스의 상성 방어는 +10을 막으며, 특성 무효에 의해 해제될 수 있다.
방어·조각·고유 특성은 기존 처리 순서를 유지한다.

속성은 cards.json의 element, 관계·이름·아이콘은 engine.js의 ELEMENT_CHART가 단일 기준이다.
51장의 HP·기술·별사탕 비용·원화·해금 조건은 변경하지 않는다.
빨간 모자는 숲의 나무, 폴리페모스는 바위의 땅, 늑대는 날카로운 발톱의 금속으로 배정한다.
이는 이야기 소재를 활용한 게임 속성이지, 원전의 설정이나 사주에 대한 사실 주장이 아니다.
