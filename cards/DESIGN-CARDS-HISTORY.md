# 우리 역사 카드 — 첫 8장

2026-09-13. 기존 장군 카드와 겹치지 않는 첫 역사 인물 묶음. ‘한국을 빛낸 100명의 위인’에서 얻은 확장 아이디어이며, 노래 가사·음원이나 정확한 수록 인물 목록을 복제하지 않는다.

## 구현

- 세종대왕 · 장영실 · 허준 · 신사임당 · 정약용 · 김홍도 · 유관순 · 김구.
- 8장 모두 원화 1024×1536 PNG + WebP, 2개 기술, 오행, 등급, 자동 능력.
- 세종은 바로 사용. 장영실·허준·신사임당·김홍도는 기존 수학 3일 연속, 정약용·유관순·김구는 7일 연속 계약을 사용.
- 카드 상세에 인물 이야기. 인물당 역사 문제 5개, 총 40개. legend: 관문을 이용해 없는 오디오로 보내지 않는다.
- 그림은 역사적 사진이나 정확한 기구 복원도가 아닌 상상화. 특히 초충도는 전칭 작품임을 명시. 의학 정보는 역사 소개이며 진료 지침 아님.
- 오행·기술·능력치·등급은 게임 설정이지 인물의 역사적 가치 평가가 아님.
- 목록의 등급은 S/A/B/C/D 한 글자만 보이며 스크린리더 설명은 유지.

## 균형

## 회귀 검사

기존 76장 데이터·컬렉션 SHA-256 및 522개 기존 소리 계획 고정. 원화 크기, 중복 캐시, 40문항, 해금과 등급 검사. 신규 카드만 변경하고 기존 카드의 균형을 덮어쓰지 않는다.

최종 검증: node --test "cards/tests/*.test.js" 299/299 통과. history-balance 6,640판 교착 0. family-balance 84장 교착 0, 재이 84% > 태오 80% > 엄마 79% > 아빠 78% 유지. collection-gallery-smoke는 4개 화면 크기에서 동일 카드 크기·정렬·바로 대결 확인. history-smoke는 3개 화면 크기에서 실제 서비스워커 오프라인 상태로 8장 그림과 인물 이야기, 수학 해금 링크, 세종 필살기 정답까지 확인. campaign-ending-smoke는 기존 원정 결말·보상·7개 버튼 회귀 통과. 브라우저 검증은 Edge의 iPad 크기 에뮬레이션이며 실제 iPad Safari의 최종 터치 검수는 별도다.
