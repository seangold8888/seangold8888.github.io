# 오행 공격 연출 — v159 릴리스

## 변경

- `element-theater.js`: 기존 Canvas 입자와 WebGL 연출 위에 별도의 제한된 2D 연출을 합성한다.
- 나무는 잎과 덩굴, 불은 연속적인 불꽃 꼬리, 물은 물결과 방울, 금속은 은빛 검광, 땅은 각진 돌 파편이다.
- 일반 공격의 준비 확대는 1.08배, 필살기는 1.16배. 필살기는 잠시 배경을 어둡게 하고 기술명을 보여 준다.
- 명중 후 여운은 460ms. 명중 호출은 기존 효과음 호출과 같은 타이머를 사용한다.
- 최대 420,000픽셀 / DPR 1.2의 추가 캔버스 한 장. 느린 프레임이 누적되면 도형 수를 줄인다. 이미지/영상 다운로드는 추가하지 않았다.
- 회피·빗나감·보조·자해만 발생한 기술에는 상대 명중 연출을 넣지 않는다. 동작 줄이기 설정, 화면 숨김, 크기 변경, 전투 초기화 때 중지한다.
- 카드 원화·능력치·엔진·기존 소리 데이터는 변경하지 않았다. 기존 번개/검/서리 WebGL 효과와 함께 동작한다.
- 앱 v72 / 공통 서비스 워커 v159. 새 JS/CSS 각 한 번만 오프라인 캐시에 등록.
