# 이야기 카드 배틀 — 미술 지시서 v1

> 작성: 클로드(기획). 대상: 코덱스 + 이미지 생성.
> 대원칙(사용자 확정): **이미지는 캐릭터 그림만.** 이름·HP·숫자·기술·별·타입 아이콘은 전부 HTML/CSS/SVG. 이미지 안에 글자·숫자·UI 요소를 절대 넣지 않는다.

## 0. 최종 선택 — 「별빛 서사화」

2026-08-30 사용자 피드백(“보는 순간 우와 하는 카드 원화”)에 따라 시안 단계는 종료하고, **프리미엄 시네마틱 스토리북 판타지 회화**로 확정한다. 특정 게임·영화의 고유 화풍이나 카드 프레임은 모사하지 않는다.

- 한 장마다 원작의 결정적 1초를 영화 포스터처럼 연출한다.
- 축소해도 얼굴·행동·핵심 소품이 즉시 읽혀야 한다.
- 깊은 남색 밤과 따뜻한 금빛 마법광, 보석색 포인트를 공통 조명 문법으로 쓴다.
- 손으로 그린 듯한 풍부한 붓질·천·유리·청동·돌의 재질감을 살린다.
- 원화가 카드의 주인공이 되도록 전투 카드에서도 그림 면적을 약 70% 확보한다.

## 1. 공통 이미지 규격

- 파일: `site/cards/art/<card_id>.png`, **1024×1536 세로형 마스터**. 배포용 WebP는 별도 생성해도 PNG 원본을 보존한다.
- 캐릭터 1명(팀 카드는 무리)이 화면 높이의 65~80%, 중앙 배치, 얼굴은 상단 1/3 안에. 핵심 정보는 중앙 72%에 둔다.
- 배경: 밤하늘 계열(진보라~남색 `#201a40`대)에 별·달빛. 캐릭터는 따뜻한 림라이트(금빛 `#ffd93d` 계열)로 배경과 분리. 배경 디테일은 흐릿하게 — 카드 UI 위에서 시끄러우면 안 됨.
- 표정: 아군(용기·지혜·마법)은 씩씩·장난기. 괴물 타입도 "무섭게"가 아니라 "으스스+귀엽게" — 초1 관객, 악몽 금지.
- 폭력 묘사 금지: 무기는 들 수 있으나 찌르는 장면·피·눈물 클로즈업 금지.
- 전 카드 동일 작화 스타일 유지 — 0절의 「별빛 서사화」 조명·붓질·재질 기준으로 통일.

## 2. 초기 스타일 3안 (기록용 — 현재는 0절의 「별빛 서사화」로 확정)

시안 카드는 **신데렐라 1장**으로 3안 제작 (능력·레이아웃 동일, 그림 스타일만 다르게).

- **A안 「별빛 인형극」**: 종이 인형극 무대 느낌. 두꺼운 색종이 질감 레이어, 또렷한 실루엣, 금박 별 장식, 무대 커튼 비네트. 허브의 '밤하늘 오락실'과 제일 가까움.
- **B안 「별자리 스테인드글라스」**: 굵은 남색 납선 + 보석색 유리 조각. 카드가 성당 창처럼 빛남. 전설 카드가 제일 돋보이는 스타일.
- **C안 「포근한 수채 동화책」**: 부드러운 수채 번짐 + 크레용 라인. 잠자리 그림책 감성, 오디오북 극장과 톤 일치.

## 3. 카드 UI 레이아웃 (HTML/CSS/SVG 영역)

```
┌────────────────────┐
│ 이름        HP ❤️60 │  ← 타입색 헤더 바
│ ⭐⭐ 레어   [타입칩] │
│ ┌────────────────┐ │
│ │  캐릭터 아트 5:4 │ │  ← 유일한 이미지
│ └────────────────┘ │
│ 특성: 유리 구두      │  ← 민트색, 원문 그대로
│ ─────────────────  │
│ 호박마차 돌진 ⭐⭐  30 │  ← 기술 행: 이름·비용·데미지
│ ─────────────────  │
│ 출전: 신데렐라(페로) │  ← 풋터
└────────────────────┘
```

- 타입색: 용기 `#C4453A` / 지혜 `#2E5FA3` / 마법 `#7A4FA8` / 괴물 `#4A4A55`. 헤더·테두리·타입칩에만 사용.
- 테두리: 허브 버튼 문법 그대로 — 두꺼운 3px 보더 + 아래 단차 그림자(`box-shadow: 0 6px 0`). 레어도별 테두리: 일반=종이색, 레어=은색, 전설=금색+은은한 반짝 애니메이션(`prefers-reduced-motion` 존중).
- 숫자는 `font-variant-numeric: tabular-nums`, HP·데미지는 카드에서 제일 큰 활자.
- 한글 서체: 시스템( Apple SD Gothic Neo / Malgun Gothic ) — 웹폰트 로딩 실패 리스크 회피, 허브와 통일.

## 5. 파이프라인 체크리스트 (코덱스용)

1. 대표 원화로 공통 조명·붓질·재질감 확정
2. 같은 스타일로 해금 4장(cinderella, fairygodmother, odysseus, polyphemus)과 기본 2장(redhood, jack) 아트 + 카드 DOM 컴포넌트 완성
3. 클로드 검수(원작 반영도·재미·금지사항) 통과 후
4. 나머지 18장 확장 — 2026-08-30 완료. 전체 24종이 PNG 원본과 WebP 배포본을 갖추며, 이미지 로딩 실패 시 실루엣+`emoji` 폴백은 계속 유지한다.
