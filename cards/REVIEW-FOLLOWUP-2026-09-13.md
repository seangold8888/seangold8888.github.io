# 카드배틀 검수 후속 수정

## 변경

- 화면에 문제를 열 때 복사한 보기만 Fisher–Yates 방식으로 섞는다. 원본 433문항 순서와 정답 ID는 유지하며, 문자열 보기의 ID도 정규화한 뒤 섞는다.
- 태오 띠 문제의 세 보기 모두 같은 길이와 형식으로 맞췄다. 정답은 파란 바탕·초록 줄 그대로다.
- 전투 카드의 본문 여백과 장식 모서리를 분리하고 이름·수치 영역을 줄어들 수 있는 격자로 바꿨다. 카드 이름과 마지막 피해/별사탕 수치가 테두리 안에 들어오도록 한다. 컬렉션 레이아웃은 변경하지 않았다.
- 배포 기록 정정: 원화 커밋 79e7429는 이후 H2 푸시에 포함되어 이미 라이브에 반영됐다. 이 후속 수정은 아직 로컬이며 push하지 않는다.
- 캐시는 기존 v107 뒤의 v108, 카드 자산은 v62 뒤의 v63. 다른 게임의 캐시 항목과 기존 카드 데이터·소리·원화는 유지했다.

## 검증

- node --test "cards/tests/*.test.js": 323개 통과.
- node cards/tools/jaewing-smoke.cjs: 폰/아이패드 3개 화면, 기술·문제·해금·오프라인 통과.
- node cards/tools/card-review-smoke.cjs: 390×844, 820×1180, 1180×820, 768×1024, 1024×768에서 85장 전체 이름·수치·장식 간격 검사. 아이패드 문서 스크롤 없음. 셜록 홈즈와 재윙 캡처를 눈으로도 확인했다.
- 정답이 세 버튼 위치 모두에서 채점되는지 검사. 단위 검사에서 6가지 보기 순열, 원본 불변, 전체 문항의 정답 ID 보존을 확인했다.
