# 컬렉션 화면 개선 · 2026-09-13

사용자 요청: 핵심 정보만 남기고 그림을 크게, 카드 크기는 일정하게, 정렬 선택 추가, 상세에서 이해하기 쉬운 능력 설명.

## 적용

- 컬렉션은 원화·이름·작은 실전 등급·체력·오행을 표시한다. 긴 피해·약점·특성 설명은 상세 화면과 기존 대결 화면에 둔다.
- 카드 외곽 비율 5:7, 이름 영역 50px, 선택한 카드도 확대하지 않아 같은 줄의 크기가 일정하다.
- iPad 세로 3열 / 가로 5열 / 휴대폰 2열. 원화가 카드 높이의 65% 이상을 차지하는지 브라우저 검사.
- 정렬: 깨어난 순(기본), 체력 높은 순, 기본 피해 높은 순, 속성순, 이름순.
- 기본 피해순은 기술의 기본 피해 기준이며 승률 순위가 아니다. 저장 키는 card_collection_sort이며, 잘못된 값·저장 차단에도 기본 정렬로 동작한다.
- 잠긴 카드도 같은 상세 화면으로 들어간다. 능력을 볼 수 있지만 출전 버튼과 실행 검증으로 출전은 막는다.
- 해금 안내·이동 버튼을 상세 맨 위에 둔다. 수학 카드 → math/, 삼국지·서유기 → sanguo/, 오디세이 → odyssey/, 오디오 이야기 → story/. 쓰구미는 없는 오디오로 보내지 않는다.
- 능력 이름은 유지하고, 설명만 화면 표시 단계에서 쉽게 풀어 쓴다. 동전 회피의 연속 회피 제한, 별사탕 최대 5개, 회복 상한, 감소 피해 조건도 설명한다.
- 상세 기술 설명의 말줄임·한 줄 자르기를 제거했다.
- 카드 탭 → 상세에서 ‘이 카드로 대결 시작’으로 즉시 출전한다. 별도 선택 단계와 하단 고정 바, 바를 위한 여백을 제거했다. 상세를 닫으면 능력만 보고 돌아갈 수 있다.
- 닫힌 상세에서 추가 클릭이 와도 중복 대결을 만들지 않는다. 전투 진입 뒤 숨겨진 컬렉션으로 초점을 되돌리지 않는다.
- 카드 데이터·해금 조건·진행 기록·엔진·소리·원화는 변경하지 않았다.
- 자산 버전 v53 / 공유 서비스워커 v94.
- 실전 등급은 원화 아래 이름 왼쪽의 작은 배지다. 기존 battleTier 평가를 그대로 사용하며 등급 계산이나 전투 데이터는 바꾸지 않는다. 체력 배지·등급·이름은 오행의 진한 바탕과 밝은 글씨로 통일한다.
- 이전 렌더러의 trait-badge가 섞여도 컬렉션 원화 위에서 숨긴다. 능력 설명은 상세 화면에 유지한다.
- latest.html은 이전 /cards/ 캐시와 다른 진입 경로에서 워커 갱신을 기다린 뒤 최신 카드 화면을 연다. 로컬 저장소를 삭제하지 않으며, 실패하면 기록을 유지한 채 재시도 버튼을 보여 준다.

## 특성 구분과 영웅 별칭

- 사용자 정정: ‘특성’은 자동 능력이 아니라 오행을 뜻한다. 자동 능력 필터와 원화 위 패시브 배지를 제거하고 오행 필터만 남겼다.
- 나무(초록·잎맥), 불(주홍·불꽃), 땅(황토·바위), 금속(은색·각진 금속), 물(파랑·물결)의 진한 바탕과 이름 영역, 서로 다른 속성 배지 형태를 적용했다. 무속성 쓰구미는 보라색이다.
- 컬렉션 셀을 5:7로 고정하고 카드는 셀 전체를 채운다. 잠금, 긴 이름, 선택, 희귀도에 따른 외곽 크기 차이와 선택 확대를 없앴다.
- 서버 파일은 최신인데 이전 화면을 먼저 돌려주는 SW 동작을 확인했다. 카드 페이지 탐색만 2.5초 제한 네트워크 우선으로 전환했다. 실패/오프라인이면 정규 주소 캐시로 복귀한다. 다른 게임 정책과 학습 기록은 그대로다.
- 기존 창작 영웅의 화면 별칭: 기어윙 → 아이언 윙, 별방패 대장 → 캡틴 스타, 천둥북 수호자 → 토르 썬더, 붉은매듭 첩보원 → 블랙 위도, 벽달림 도마뱀 → 스파이더 키드, 네온도약자 → 마일스 점퍼, 달빛 나방수호자 → 고스트 스파이더.
- 원화를 마블 인물화로 바꾸는 작업은 아니다. 별칭은 CardView에서 적용하고 카드 로드 시 화면용 복사본에 반영한다. 카드 문제도 같은 표시 이름을 사용한다. 원본 cards.json, ID, 해금·저장 키, 엔진, 소리는 그대로다.

## 검증

- 전체 자동 검사 295개 통과.
- collection-gallery-smoke.cjs: 격리된 실제 브라우저에서 820×1180, 1180×820, 390×844, 1317×1085의 76장 동일 크기, 원화 비중, 다섯 정렬, 재접속 후 정렬 유지, 잠긴 카드의 상세와 출전 차단, 해금 이동 경로, 상세에서 직접 출전, 중복 시작 방지와 컬렉션 복귀 확인.
- campaign-ending-smoke.cjs: 실제 서비스워커를 설치하고 오프라인으로 전환한 뒤 결말·합류·카드 대결·문제 열기 확인.
- 오행 필터, 다섯 테두리 색 차이, 패시브 배지 제거, 별칭 일치와 카드 문제 이름 검사. 실 서비스워커 캐시에 옛 HTML을 넣은 후 최신 페이지가 먼저 나오고 그 페이지가 오프라인에서도 열리는지 검증했다.
- 실제 iPad 기기 성능이나 아이 반응까지 검수했다는 의미는 아니다.
- 공개 사이트에는 아직 배포하지 않았다.
- v52 추가 검증: 컬렉션/PWA 검사 30개 및 실제 워커의 최신 진입 링크 → 저장 기록 유지 → 오프라인 대결 흐름 통과.
- v53 검증: 컬렉션/PWA 검사 30개, 네 화면 크기의 76장 모두 등급·이름·체력과 그림 사이 겹침 없음, 이름 잘림 없음, 등급과 체력의 색상 일치 확인. 이전과 같은 카드 크기·원화 비중 유지.
