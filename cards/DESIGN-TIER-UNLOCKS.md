# 등급별 카드 획득 조건

2026-09-13. 전투 능력치와 기존 cards[] 데이터는 바꾸지 않는다. 카드에 표시되는 CardView.battleTier의 S~D 등급을 기준으로 cards.json의 tierUnlockGoals를 적용한다. 체력 하나가 아니라 기존 전투 평가에 따른다.

| 등급 | 이야기/게임 카드에 추가되는 수학 | 수학 전용 카드의 새 조건 |
|---|---|---|
|D|추가 없음|누적 1일 + 5문제|
|C|추가 없음|누적 2일 + 10문제|
|B|누적 1일 + 10문제|누적 3일 + 20문제|
|A|누적 3일 + 30문제|누적 5일 + 40문제|
|S|누적 5일 + 60문제|누적 7일 + 70문제|

- 이야기/게임 카드는 원래의 완청/클리어 조건도 모두 충족해야 한다. 수학만으로 이야기를 건너뛰지 않는다.
- 수학 전용 카드는 기존 streak3/7 대신 새 누적 목표를 쓴다. 두 목표는 AND이며 문제나 날짜를 소모하지 않는다. 여러 카드에 같은 기록이 인정된다.
- 기본 지급 카드는 계속 무료. 가족은 DESIGN-FAMILY-UNLOCKS.md의 더 높은 목표 유지. 원정 영입은 별도의 보상 경로이며 쓰구미는 원정 결말 조건 그대로다.
- 기존 story_done_*와 게임 클리어 플래그에는 날짜가 없다. 최초 새 버전 방문 때 이미 충족된 자격을 보존한다. 수학은 2026-09-13까지 기록된 과거 날짜의 기존 연속 조건 달성을 보존한다.
- 영구 획득 장부 card_collection_unlocks_v1 = {version:1,unlocked:[id]}를 쓴다. 최초 로드 시 전체 카드를 읽은 뒤 초기화해, 이후 이야기 완청이 마이그레이션으로 잘못 인정되지 않게 한다.
- preview=all은 장부 초기화/지급을 저장하지 않는다. 저장소를 쓸 수 없으면 현재 페이지 내에서만 보존할 수 있다.
- 잠긴 상세에는 기존 조건 + 등급별 목표 + 현재 진행률을 함께 보여 준다. 원래 이야기/게임이 남았으면 그쪽으로, 완료했으면 수학으로 이동한다.
- 메인 수학/수학놀이터 누적 기록을 공유한다. 영어 읽기, 부모 모드, 원정 승리를 수학 문제 수로 세지 않는다.
- 등급표를 추후 바꾸면 신규 획득 목표도 함께 바뀐다. 이미 지급된 카드는 회수하지 않는다.

검증: node --test "cards/tests/*.test.js", node cards/tools/tier-unlocks-smoke.cjs. 브라우저 스모크는 폰 세로/태블릿 세로/가로, 실제 서비스워커 오프라인, 기존 자격 보존을 다룬다. 실제 iPad Safari 기기 확인은 별도다.

카드 모듈 v58 / 공유 캐시 v99. 공개 배포 별도.

최종 검증: 카드 테스트 316/316 통과. tier-unlocks-smoke와 family-unlocks-smoke 모두 820×1180, 1180×820, 390×844에서 통과. 기본 카드, 원정 가족 출전/문제 관문, 추가 목표 AND 경계, 기존 자격 이전, 획득 영구 유지, 실제 오프라인 새로고침을 확인했다. 폰의 조건 안내 스크린샷도 확인했다. 이전 커밋과 비교하여 84개 카드 객체와 가족 획득 목표가 완전히 동일함을 검사했다.
