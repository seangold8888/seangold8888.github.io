# S3 완료 · 2026-09-13

## 구현 범위

- 설계서 부록의 2~7장 도입·보스 직전·복원 문구를 그대로 연결했다.
- 프롤로그부터 7장까지 총 29전투를 이어서 진행한다.
- 결말 네 장면을 순서대로 보고 나서만 쓰구미 대마왕이 합류한다.
- 결말 장면 번호를 저장하며, 새로고침하면 해당 장면 첫 줄부터 이어 본다.
- 마지막 완료 콜백을 반복해도 합류·결말 횟수가 중복되지 않는다.
- 기존 v1 저장에는 endingScene이 없어도 진행·합류 기록이 유지된다.
- 아침 장면은 기존 수학 게임 가족 그림을 재사용한다.
- 쓰구미는 기존 카드 75장을 바꾸지 않고 76번째 카드로 추가했다.
- 기술 네 개, 기존 gas/body 재질, 카드 문제 다섯 개, 크롭 좌표, 컬렉션·일반 대결 해금까지 연결했다.
- 잠긴 쓰구미는 “원정을 끝까지 가면 만날 수 있어!”로 안내하며, 없는 오디오로 보내는 버튼을 숨긴다.
- 보스 쓰구미 140 HP / 합류 카드 100 HP. 기존 보스 보정은 4fd314d의 균형을 유지한다.
- 카드 자산 v46, 공유 서비스워커 v87. 쓰구미 WebP·아침 가족 그림도 오프라인 저장 대상이다.

S4의 수련 연동·새 원정은 이번 S3 범위가 아니다. 설계서 부록의 후반 문구는 기존 초안을 그대로 적용했으며, 아이 반응에 따른 대사 수정은 하지 않았다.

- 새 카드의 일곱 버튼을 세 화면 크기에서 스크롤해 모두 누를 수 있는 위치까지 노출되는지 확인했다. 휴대폰은 기존 가로 스크롤 기술 목록을 사용한다.
- 실제 iPad 하드웨어·Safari 성능·아이의 반응까지 확인했다는 뜻은 아니다.

### 재실행

Playwright는 설치된 런타임의 NODE_PATH를 지정해 두 브라우저 도구를 실행한다. 두 도구 모두 자체 localhost 서버와 격리 브라우저를 만들며, 사용자의 저장 기록은 변경하지 않는다.
