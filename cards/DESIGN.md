# 이야기 카드 배틀 — 게임 설계서 v1

> 작성: 클로드(기획) → 구현: 코덱스. 이 문서가 단일 기준(source of truth).
> 카드 스탯 데이터는 `cards.json`, 미술 지시는 `ART_DIRECTION.md` 참조.

## 0. 제품 한 줄

퍼블릭 도메인 명작 캐릭터로 싸우는 초등 저학년용 카드 배틀.
포켓몬 TCG 골격(HP·기술·약점·동전) + 하스스톤 마나(별사탕 자동 램프).
오디오북(`/story/`)을 끝까지 들으면 카드가 해금된다.

## 1. 대상·환경

- 플레이어: 초1 (김재이). 글은 읽지만 긴 문장은 부담 → 아이콘+숫자 중심 UI.
- 기기: 아이패드 Safari 가로 모드 우선, 홈 화면 앱 실행. 데스크톱은 덤.
- 경로: `site/cards/` → `seangold8888.github.io/cards/`
- 허브 등록: v1 완성 후 index.html 게임 목록에 카드 추가 (수학 관문 안쪽, 다른 게임과 동일).

## 2. v1 범위 (이것만 만든다)

- **1:1 맞대결**: 내 카드 1장 vs 컴퓨터 카드 1장. 대기석·교체·소환 없음.
- 시작 전 내가 해금 카드 중 1장 선택. 컴퓨터는 대표 v1 카드 중 내 카드와 레어도 차이가 ±1 이내인 상대를 랜덤 선택한다. 범위 안의 다른 카드가 하나도 없으면 높은 레어도 상대 대신 같은 카드 미러전을 사용한다.
- 승리 = 상대 카드 기절(HP 0).
- 별사탕: 두 쪽 다 턴 시작에 +1 (최대 5 저금). 소환이 없으므로 v1에서 별사탕은 기술 비용 전용.
- 동전 던지기: 화면 중앙 큰 동전 애니메이션. 내 기술 판정은 아이가 직접 탭하고, 컴퓨터 판정은 자동 회전하되 결과를 공격보다 먼저 보여 준다.
- 기절 시: 승리 팡파르 + "다음 이야기를 들으면 새 친구가 온다" 안내로 /story/ 유도.
- **v2로 미루는 것**: 대기석 2장, 교체, 소환 비용, 덱 8장, 아빠 대전(핫시트), 진화.

## 3. 턴 구조 (고정 3단계)

```
① 별사탕 +1 (최대 5)
② 기술 1개 선택 (비용 지불 가능한 것만 활성화)
③ 데미지 적용 → 상대 턴
```

- 기술 비용을 낼 수 없으면 "쉬기" 버튼(별사탕 모으기)만 활성.
- 약점 타입 공격이면 데미지 ×2, 화면에 "×2!" 크게 표시.
- 컴퓨터 AI: 낼 수 있는 기술 중 데미지 기대값 최대를 선택. 단 마무리 가능하면 무조건 마무리. 그 외 30% 확률로 두 번째 좋은 수(아이가 이길 여지).

## 4. 데이터 계약

- `cards.json` 스키마:

```json
{
  "id": "cinderella",
  "name": "신데렐라",
  "emoji": "👠",
  "type": "wise",            // brave | wise | magic | monster
  "rarity": 2,               // 1 일반 ⭐ / 2 레어 ⭐⭐ / 3 전설 ⭐⭐⭐
  "summonCost": 2,           // v1 미사용, v2 대비
  "hp": 60,
  "passive": { "name": "유리 구두", "desc": "...", "fx": "revive_half_once" },
  "attacks": [
    { "name": "호박마차 돌진", "cost": 2, "dmg": 30, "fx": null, "desc": "" }
  ],
  "unlock": "cinderella",    // /story/ 에피소드 id. null = 기본 지급
  "art": "art/cinderella.png"
}
```

- `fx` 코드 (v1 구현 대상만):
  - `revive_half_once` 기절 시 1회 HP 절반 부활
  - `reduce_dmg_10` / `reduce_dmg_20_monster` 받는 데미지 감소
  - `coin_evade` 피격 시 동전 앞면 = 회피
  - `coin_miss` 공격 시 동전 뒷면 = 빗나감
  - `dmg_half_enemy_hp` 데미지 = 상대 남은 HP 절반(내림, 10단위)
  - `dmg_stack_10` 사용마다 +10 누적
  - `skip_next_enemy` 상대 다음 턴 기술 금지 (동전 조건은 `coin_` 접두)
  - `gain_star_1` / `steal_star_1` 별사탕 획득/훔침
  - `heal_40` 자기 HP 40 회복 (v1: 대상=자신)
  - `self_hurt_10_eot` 턴 종료마다 자기 HP -10
  - `first_hit_zero` 처음 받는 공격 무효
  - `wish_limit_3` 판당 기술 사용 총 3회 제한
  - 나머지 fx(벤치 관련)는 v2 — 효과를 무시한 채 버튼만 노출하는 반쪽 구현은 금지한다. v1 기술이 하나도 없는 카드는 v1 풀에서 제외하고, v1 기술이 남는 혼합 카드는 v2 기술만 숨긴다.
  - 요정 대모는 「별가루 톡!」과 「호박 마법」이 완전한 v1 기술이므로 포함하며, 대상이 없는 부활 기술만 v2까지 숨긴다. 눈의 여왕도 「얼음 거울」이 완전한 v1 기술이므로 포함한다. 브레멘 음악대·손오공·과자집 마녀·아서왕·콩나무 거인은 v1 기술 보강 전까지 제외한다.
  - 로딩 시 card.v1이 false가 아니며 v1 가용 기술이 1개 이상인 카드만 풀에 넣도록 검증한다.

## 5. 해금 연동 (이미 작동 중인 것에 붙이기)

- `/story/` 플레이어가 완청 시 `localStorage["story_done_<episodeId>"] = "1"` 기록 중.
- 카드 해금 판정: `card.unlock === null || localStorage["story_done_" + card.unlock] === "1"`.
- 같은 도메인(github.io)이라 localStorage 공유됨. 경로 무관.
- 잠긴 카드는 컬렉션 화면에 실루엣+자물쇠로 표시, 탭하면 "「○○」 이야기를 끝까지 들으면 만날 수 있어!" + /story/ 링크.
- 전체 컬렉션은 cards.json의 collection 목록에 적힌 24장이다. 첫 6편 완청 기준으로는 기본 2장에 cinderella(신데렐라·요정 대모), odyssey_cyclops(오디세우스·폴리페모스), threepigs(아기돼지 삼형제), tortoisehare(토끼와 거북), redhood_story(커다란 늑대), jack_story(콩나무 거인)가 더해져 10장이 활성화된다. 나머지도 각 이야기의 `story_done_*` 기록으로 같은 방식으로 깨어난다.
- 아기돼지 삼형제·토끼와 거북·커다란 늑대는 해금 즉시 v1 1:1 대전에 출전 가능하다. 콩나무 거인은 해금·수집 대상이지만 v1: false이며, 컬렉션에서 “대전 준비 중”으로 표시하고 선택·대전할 수 없게 한다.
- 최소 시작 보장: 아무것도 해금 안 됐으면 빨간 모자·콩나무 잭 2장 기본 지급(unlock: null로 지정).

## 6. UI 원칙 (사용자 확정 사항 — 위반 금지)

1. **이미지는 캐릭터 그림만.** 카드 이름·HP·기술명·숫자·별·타입 아이콘은 전부 HTML/CSS/SVG 텍스트 레이어. 한글 선명도 + 밸런스 숫자 즉시 수정 가능해야 함.
2. 카드 = DOM 컴포넌트. `cards.json` 수정 → 새로고침만으로 반영.
3. 비주얼 톤 = 허브 「밤하늘 오락실」 계열 (`--night #201a40`, `--star #ffd93d`, `--paper #fff6e6`, 두꺼운 테두리 + 아래 그림자 버튼). 세부는 ART_DIRECTION.md.
4. 아이패드 터치 규격: 탭 타깃 최소 60px, `-webkit-user-select:none`, `touch-action` 관리, 고무줄 스크롤 차단 — 기존 게임들 head 패턴 복사.
5. 소리: 타격·동전·승리 효과음은 WebAudio 합성(외부 에셋 금지). 음소거 토글.

## 7. 검수 기준 (5단계에서 클로드가 볼 것)

- 원작 반영도: 능력이 원작 장면과 연결되는가, 미술 지시서의 금지사항(디즈니 요소) 준수.
- 재미: 초1이 3턴 안에 "다음에 뭘 할지" 스스로 결정 가능한가. 한 판 3분 이내.
- 숫자 검산: 모든 HP·데미지 10의 배수, 약점 ×2 포함 오버킬 밸런스.

## 8. v1.5 업데이트 지시 (2026-08-31, 사용자 피드백 반영)

### 8a. 반영 완료 (클로드)
- 컬렉션 정렬: 깨어난 카드 → 깨울 수 있는 대전 카드 → 수집 전용 순. 묶음 내 원래 순서 유지 (app.js shelfOrder).
- 기술 다양화 1단계: 모든 v1 카드가 기술 2개 이상 (cards.json — 잽/유틸 추가, 기존 fx 코드만 사용, 엔진 무수정). "1별 잽을 쓸까, 모아서 한 방을 칠까"의 매턴 선택지 생성.

### 8b. 코덱스 구현 몫 ① — 타격음 임팩트 (사용자: "타격음이 아직 부족")
- 문제: 타격이 "맞았다"는 쾌감 부족. 방향 = 트랜지언트와 저역.
- 어택 3ms 이내 순간 피크(현재 shape 어택이 부드러워 뭉개짐), 60~110Hz 사인 바디를 지금의 1.5~2배 게인으로, 소프트 클리핑(waveshaper)으로 눌러 따뜻하게.
- 강타(약점 ×2)는 일반타와 확실히 구분: 저역 2배 길게 + 노이즈 크랙 + 화면 흔들림(CSS)과 동기.
- 타격 순간 룸센드는 줄이고(잔향이 임팩트를 흐림) 꼬리에만 잔향.
- 음량 상한은 유지 (아이패드 스피커, 초1 청력 보호).

### 8c. 코덱스 구현 몫 ② — 「이야기의 조각」 시스템 (사용자: "공격이 단순, 머리 쓰게")
매턴 "제일 센 기술 누르기"를 넘어서는 의사결정 레이어. 벤치(v2)보다 작은 공사로 깊이 추가.

- 대결 시작 시, 내가 **깨운 카드들의 이야기에서 조각 3개**가 무작위로 손패에 들어온다 (컴퓨터도 동일 규칙).
- 조각은 **판당 각 1회용**, 내 턴에 기술 대신이 아니라 **기술과 함께** 1개 사용 가능 (턴 구조: 별사탕 → 조각(선택) → 기술).
- 조각 효과는 원작 소품에서 (기존 fx 재사용 가능한 것 우선):
  - 유리 구두(신데렐라): 이번 턴 받는 데미지 0 (coin 없이 확정 회피 1회)
  - 호박 마차: 이번 기술 데미지 +20
  - 벽돌 한 장(아기돼지): 다음 받는 데미지 -30
  - 떡 하나(해와 달): 별사탕 +2
  - 황금 거위 알(잭): HP +30
  - 여의봉 조각(손오공): 이번 기술 비용 -1
  - 참기름(해와 달): 상대 다음 기술 동전 앞면이어야 명중
  - 대동강 물 한 바가지(봉이 김선달, 추후): 상대 별사탕 1개를 내 것으로
- 깨운 이야기가 많을수록 조각 풀이 커진다 → 듣기 루프 강화. 최소 풀(이야기 2개)일 때도 작동해야 함.
- UI: 손패 3장을 화면 하단 기술 바 위에 작은 칩으로. 탭 = 미리보기, 다시 탭 = 사용. 사용한 조각은 뒤집힘.
- AI: 조각 사용 규칙 단순하게 — 마무리 가능하면 강화 조각, HP 절반 이하면 방어/회복 조각, 그 외 30% 랜덤.
- 테스트: 조각 효과 각각 + "조각 없이도 게임 성립" 경로.

### 8d. 검수 기준 추가
- 초1 기준: 조각 이름·아이콘만 보고 효과가 연상되는가.
- 한 판 여전히 3분 이내인가 (조각 고민으로 5분 넘어가면 실패).

### 8e. 캐시 규칙 (코덱스 공통)
- index.html의 스크립트 태그는 `?v=N` 버전 쿼리를 단다. JS를 고치면 반드시 N을 올린다 — 아이패드 사파리가 예전 스크립트를 붙들고 있는 사고가 실제로 났음.
