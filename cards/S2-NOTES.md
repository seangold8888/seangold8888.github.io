## 구현 범위

- 컬렉션 상단 원정 버튼 → 세계 8개 지도 → 장면 → 편성 → 상대 확인 → 기존 전투 화면 → 결과 → 되돌림·합류.
- 플레이 범위는 **프롤로그와 1장**이다. 1장 완료 시 신데렐라를 합류시키고 2장 시작 상태를 저장하지만, 이후 장은 준비 중으로 표시한다. 결말·새 원정·쓰구미 카드는 열지 않는다.
- `campaign-ui.js`는 S1 상태 API만 호출한다. 상대의 HP 보정과 AI 실수율도 `Campaign.encounter`에서 가져온다. 대결 결과는 즉시 저장하고 중복 결과 콜백은 무시한다.
- 장면을 끝까지 읽은 뒤에만 합류한다. `isUnlocked`는 원정 합류를 기존 해금 조건에 추가한다. 이야기로 먼저 연 카드는 원정 후보를 늘리지 않는다.
- 전투 도중 나가거나 새로고침하면 같은 상대의 출전 선택으로 돌아간다. 패배는 해당 카드만 쉬게 하며 전원 패배하면 같은 장 처음부터 다시 시작한다.
- 진행 저장 실패 시 경고를 표시하며 현재 창에서는 계속 플레이할 수 있다.
- 기존 75장 데이터·그림·소리와 엔진은 변경하지 않았다. 수련은 현재 미구현이므로 §9 지침대로 S4로 남긴다.

## 화면

- 기존 원화를 지도·편성·장면에 재사용한다. 지도 크롭은 얼굴이 보이도록 따로 설정했다.
- 장면은 한 줄씩 탭으로 공개한다. 음성 합성·내레이션은 추가하지 않았다.
- 되돌린 세계의 낙서 스티커가 떨어지고 체크 표시가 남는다. 모션 줄이기 설정에서는 애니메이션을 생략한다.
- 아이패드 세로 820×1180, 가로 1180×820에서 편성과 전투가 화면 높이 안에 들어간다. 상단바가 72→60px로 애니메이션되는 동안 화면이 12px 넘치던 현상을 재현해, 전투 상단바의 높이 전환을 끄고 효과의 화면 경계도 제한했다. 진입 즉시와 안정 후를 모두 검사한다.
- 폰 390×844에서는 페이지 세로 스크롤을 허용한다. 태오 기술 4개 + 방어 + 필살기 + 별사탕 7개 행동은 전부 유지하며, 행동 줄을 가로 스크롤한다. 기존 필살기 grid-column 규칙과 긴 설명 때문에 잘리던 버튼 행도 수정했다.

브라우저 스크립트는 Playwright와 Edge가 필요하다. 별도의 로컬 서버와 격리 컨텍스트를 사용하므로 실제 사용자 진행을 바꾸지 않는다. 테스트가 끝나면 서버와 브라우저를 닫는다. 스크린샷은 시스템 임시 폴더에 남긴다.

원정 브라우저 검사는 실제 엔진으로 프롤로그를 플레이한다. 이후 승패·휴식·합류·S2 경계 검사는 **테스트에만 있는 결과 주입**으로 화면 흐름을 재현한다. 이를 실제 아이의 승률 검증으로 보지 않는다. 균형은 별도의 S1 시뮬레이션으로 검사한다. 공개 앱에는 승패 주입 기능이 없다.
