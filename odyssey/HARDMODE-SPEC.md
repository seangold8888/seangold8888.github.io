# 오디세이 1장 「키클롭스 동굴」 — 어려운 길 (하드 모드) 스펙

작성: 2026-09-08 · 기획 클로드 / 구현 코덱스
대상 파일: `site/odyssey/index.html` (단일 번들), `site/sw.js`
플레이어: 김재이 (초1). 이 스테이지를 제일 좋아하고 이미 여러 번 클리어함.

## 0. 왜 만드는가

지금 1장은 **점프 하나뿐인 오토러너**다. 폴리페모스는 히트박스도 HP도 없는 배경 그림(`A.drawCyclops`, index.html:3676)이고, 하트 5개가 다 닳아도 무제한 재시작이라 사실상 실패가 없다.

그래서 **속도만 올리는 난이도 상승은 금지**한다. 반응속도 시험이 될 뿐 새 재미가 없고, 자동 보정(assist)이 곧바로 되돌려 버린다.

대신 두 가지를 넣는다.

1. **동사를 하나 늘린다** — 슬라이드. 버튼이 둘이 되면 "무엇을 할까"라는 판단이 생긴다. 마리오에 밟기가 추가된 것과 같은 효과.
2. **자원을 하나로 만든다** — 폴리페모스와의 거리. 하트 5개(사실상 무의미) 대신 실수가 누적되는 게이지 하나. 배경 그림이던 거인이 진짜 추격자가 된다.

## 1. 절대 규칙 (스코프 가드)

- **일반 모드의 플레이 감각은 1도 바뀌면 안 된다.** 새 상수·새 분기는 전부 `const HARD = !!options.hard;` 뒤에 둔다. `HARD === false`일 때 프레임 단위 거동이 지금과 동일해야 한다.
- 새 장애물 타입은 하드 전용 레벨 데이터에만 넣는다. 기존 `hazards`/`drops`/`stars` 배열의 좌표는 **건드리지 않는다**.
- 게임 오버는 여전히 없다. 잡혀도 아테나 화면 → 체크포인트 재시작. 초1이 혼자 하는 게임이다.
- 세로 화면 차단, `prefers-reduced-motion`, 음소거, 일시정지 등 기존 접근성 처리는 그대로 유지.
- 새 파일을 만들지 말고 `odyssey/index.html` 안의 해당 모듈 블록에 넣는다 (`/* src/stages/cyclops-level.js */`, `/* src/stages/runner-controller.js */`, `/* src/stages/cyclops.js */`, `/* src/art/cyclops.js */`, 진행도 모듈).

## 2. 기능 1 — 슬라이드 (숙이기)

### 2.1 왜 "천장"인가

바닥 장애물을 슬라이드로 통과하는 건 아이에게 말이 안 된다. 그래서 매핑을 **모호함 없이** 나눈다.

| 위험 위치 | 행동 |
|---|---|
| 바닥에 있는 바위 (`small`/`tall`/`wide`/`drop`) | 점프 |
| 천장에서 내려온 것 (새 타입 `hang`) | 슬라이드 |

기존 `wide`는 **계속 점프로 넘는다**. 바꾸지 말 것.

### 2.2 조작

- 입력: `down` (↓ / S). 이미 `E.input` 맵(index.html:1589)에 있음.
- 터치: 점프 버튼 왼쪽에 두 번째 원형 버튼 「숙여 ↓」. 좌표 `x: W - 214, y: H - 86, r: 52`. 점프 버튼과 같은 방식(`jumpButton`, index.html:4127)으로 `pointerId` 추적 + `setHeld('down', ...)`. 하드 모드에서만 그린다.
- 멀티터치: 점프와 슬라이드를 동시에 누를 수 있어야 한다. `pointerId`를 버튼별로 따로 잡을 것 (지금 점프 버튼이 `pointerId === null`도 받아들이는 부분은 두 버튼이 되면 서로의 up을 훔친다 — **버튼별 id 일치일 때만 해제**하도록 고칠 것).

### 2.3 동작 (`RunnerController`, index.html:3388)

새 필드: `sliding`(bool), `slideTime`, `slideCooldown`.

```
SLIDE_DURATION   = 0.55   // 초
SLIDE_COOLDOWN   = 0.12   // 끝난 뒤 다시 누를 수 있기까지
SLIDE_HEAD       = 44     // 슬라이드 중 머리 높이 (평소 91)
```

규칙:
- 땅에 있고 `slideCooldown <= 0`일 때 `down`을 **누르는 순간** 슬라이드 시작. `buffered('down', 0.16)`로 입력 버퍼를 쓸 것 (점프와 동일한 관용).
- `down`을 계속 누르고 있어도 `SLIDE_DURATION`이 지나면 자동으로 일어선다. 길게 누르기로 무한 슬라이드 금지.
- 슬라이드 중 **점프는 언제든 가능**하고 즉시 슬라이드를 취소한다. (막히는 느낌 방지)
- 공중에서 `down`은 지금처럼 빠른 낙하(중력 ×1.18, index.html:3479). **착지 시점에 `down`이 눌려 있으면 자동으로 슬라이드로 이어진다.** 「넘고 → 숙이고」 리듬이 한 번의 누름으로 읽힌다.
- 슬라이드 중에도 좌우 오프셋(−48/+58)은 그대로.

연출: 몸을 앞으로 눕히고(스케일 `sx 1.22 / sy 0.62`), 발밑 먼지 `F.dust`, 스피드라인 1줄, `S.step()` 대신 짧은 미끄러짐 소리. 새 사운드가 부담되면 `S.whoosh()` 볼륨 낮춘 것으로 대체 가능.

### 2.4 히트박스

`updateHazards`(index.html:4367)의 플레이어 박스:

```
pTop = player.y - (player.sliding ? 44 : 91)
```

나머지(`pLeft/pRight/pBottom`)는 그대로.

새 타입 `hang`은 천장에서 내려온 위험이므로 **아래에서 위로가 아니라 위에서 아래로** 판정한다:

```
// hang: 천장 y=0 에서 (ground - clear) 까지 막혀 있다
hazard.clear = 58   // 이 높이 아래로 숙이면 통과
겹침 = pRight > sx - hazard.w + 10
     && pLeft  < sx + hazard.w - 10
     && pTop   < level.ground - hazard.clear
```

즉 서 있으면(머리 91) 걸리고, 숙이면(머리 44) 통과. `clear`는 58 고정.

**주의:** `hang`은 점프로 절대 피할 수 없어야 한다 (점프하면 더 확실히 맞는다). 이게 "점프 만능"을 깨는 지점이다.

### 2.5 가르치기

하드 모드 첫 `hang`은 **데모**다. `demo: true`면 접촉해도 데미지 없이 부서지고(기존 낙석 데모와 동일, index.html:4349), 힌트가 뜬다.

- `showHint('거인의 손이 내려와! ↓ 를 눌러 숙여!')` — 안전 구간 안에서.
- 그 앞 400px 구간에 별을 **낮게**(`GROUND - 30`) 한 줄 깔아 자연스럽게 숙이게 유도. 별길이 조작을 가르치는 기존 원칙(index.html:3341 주석) 유지.
- `hang` 접근 시 기존 낙석과 같은 경고음 3틱(`S.warning`)을 쓴다.

## 3. 기능 2 — 폴리페모스 추격

### 3.1 자원 교체

하드 모드에서는 **하트를 쓰지 않는다.** `hearts` 대신 `lead`(거인과의 거리) 하나.

```
LEAD_MAX      = 100
LEAD_START    = 62
LEAD_REGEN    = 6.5   // 초당, state === 'run' 일 때만
LEAD_HIT      = -26   // 바위/손에 맞을 때
LEAD_STAR     = 1.2   // 별 하나
LEAD_COMBO3   = 4     // 3연속 별 보너스 (combo === 3 인 프레임에 1회)
LEAD_REST_MUL = 1.6   // restZones 안에서 회복 배율
LEAD_CHECKPT  = 70    // 체크포인트 통과 시 max(lead, 70)
```

- `hit()`(index.html:4198)에서 `hearts--` 대신 `lead += LEAD_HIT`. `hitSlow = 0.7`은 그대로 → 맞으면 느려지고, 느려지면 거리가 더 줄어드는 복리 효과가 생긴다. 이게 긴장의 핵심이다.
- `lead <= 0` → 기존 `state = 'rescue'` 그대로 (아테나 화면). 재시작 시 `lead = LEAD_START`.
- `updateCheckpoints`(index.html:4453)의 `hearts + 1` 대신 `lead = Math.max(lead, LEAD_CHECKPT)`.
- `lead`는 항상 `[0, 100]`으로 클램프.

### 3.2 거인을 실제로 움직인다

`A.drawCyclops`(index.html:3676)는 지금 `x = 30 - view.dist * 0.002 + climax * 22`로 사실상 고정이다. 하드에서는 `view.lead`가 있으면 그것을 쓴다:

```
// view.lead 가 undefined 면 (일반 모드) 기존 식 그대로.
const near = 1 - lead / 100;              // 0 = 멀다, 1 = 코앞
x     = -170 + near * 340;
scale = 0.83 + near * 0.30;
alpha = 0.62 + near * 0.30;
```

`makeView()`(index.html:4573)에 `lead`를 실어 보낼 것. 일반 모드에서는 `lead` 키를 **넣지 않는다**(그림 코드가 옛 경로를 타도록).

추가 연출 (`lead` 구간별):
- `lead < 45`: 화면 왼쪽 가장자리에 보라색 비네트, 알파 `(45 - lead) / 45 * 0.35`.
- `lead < 30`: 3.5초마다 `S.warning(2)` 급의 낮은 포효 + `F.addShake(0.14, -1, 0)`.
- `lead < 15`: 비네트 맥동 주기 2배, 거인 팔이 화면 안까지 들어옴(순수 연출, 히트박스 없음).

포효는 **음소거 상태를 존중**해야 하고, `prefers-reduced-motion`이면 흔들림을 생략한다.

### 3.3 HUD

`drawHUD`(index.html:4605)에서 하드 모드일 때 하트 줄(`UI.drawHearts`)을 **거리 바**로 교체:

- 위치: 하트가 있던 자리 `x 28, y 30, w 210, h 22`, 라운드 사각.
- 왼쪽 끝에 작은 거인 머리 아이콘, 오른쪽 끝에 오디세우스 아이콘. 채워진 길이 = `lead / 100`.
- 색: `lead > 55` `#7ed9aa`(초록) / `30~55` `#ffcf5e`(호박) / `< 30` `#ff8f86`(빨강). 색만으로 구분되지 않게 **아이콘 사이 간격 자체가 줄어드는** 것으로도 읽히게 할 것 (색각 배려).
- 별 카운터·진행 바·일시정지·음소거는 그대로.
- 화면 낭독(`UI.announce`)은 `lead`가 30 밑으로 처음 떨어질 때 한 번 "거인이 가까워졌어요! 별을 주우면 다시 멀어져요." (매 프레임 낭독 금지)

## 5. 하드 레벨 데이터

`ODY.Levels.cyclops.build()`(index.html:3300)를 `build(options)`로 바꾸고 `options.hard`일 때만 추가 데이터를 얹는다. 기존 반환 구조는 유지.

`hang` 배치 (좌표는 기존 `hazards`와 겹치지 않게):

```
{ x: 3720, w: 46, clear: 58, demo: true,  group: '거인의 손' },   // 시범, 무해
{ x: 5020, w: 44, clear: 58, group: '거인의 손' },
{ x: 6650, w: 48, clear: 58, group: '거인의 손' },
{ x: 8420, w: 46, clear: 58, group: '거인의 손' },
{ x: 9980, w: 44, clear: 58, group: '거인의 손' },   // 두 번째 쉼터 직후
{ x: 11380, w: 50, clear: 58, group: '거인의 손' },  // 낙석 11340 과 연결 — 점프 후 즉시 숙이기
{ x: 12250, w: 46, clear: 58, group: '거인의 손' }
```

- 11340(낙석) → 11380(손)은 **의도된 연결기**다. 점프로 낙석을 넘고, 착지하면서 `down`을 유지해 슬라이드로 손을 통과한다. 2.3의 "착지 시 자동 슬라이드"가 이 구간을 위해 존재한다. 간격이 빡빡하면 11380 → 11430으로 조정 가능.
- `hang`은 `restZones`(5200~5850, 9600~10200) 안에 두지 말 것.
- 모든 `hang` 앞 300px에 낮은 별 줄(`GROUND - 30`, gap 60, 4개)을 깔아 숙일 자리를 알린다.

`type: 'hang'` 그림: 천장에서 내려온 거인의 손가락/종유석. `A.cyclops`에 `drawHang(ctx, sx, hazard, t)` 추가. 접근 시 `hazard.wobble`로 흔들리게(기존 바위와 동일한 신호 언어).

## 6. 해금 · 저장

### 6.1 스키마 v3

`normalizeProgress`(index.html:14264)를 version 3으로 올린다. **v2 저장을 잃지 말 것** — 없는 필드는 기본값으로 채우고, 기존 `cleared`/`bestStars`는 그대로 보존.

```js
clean.stages[id] = {
  cleared:     !!stage.cleared,
  bestStars:   0 이상 정수,
  hardCleared: !!stage.hardCleared,   // 새로 추가
  bestLead:    0 이상 정수            // 새로 추가, 하드 클리어 시점의 lead
};
```

`wisdom`은 **하드 클리어로 늘리지 않는다** (지혜의 별 = 장 최초 클리어 수라는 기존 의미 유지). `getUnlockedStageIds`/`getStartRoute`는 지금 그대로 동작해야 한다.

`applyStageResult(value, id, stars, opts)`에 `opts.hard` 추가:
- 하드 클리어 → `hardCleared = true`, `bestLead = max(기존, 결과 lead)`. `cleared`는 이미 true.
- 별은 하드에서도 `bestStars`에 반영(최대값 갱신).

### 6.2 스테이지 고르기

`definitions.cyclops`(index.html:14680 근처)에 하드 진입점을 추가한다.

- 조건: `progress.stages.cyclops.cleared === true`.
- 카드 아래에 작은 버튼 「🔥 어려운 길」 (`w: 132, h: 44`, color `#ff9a6b`). 잠겨 있으면 그리지 않는다(자물쇠도 그리지 않음 — 아직 존재를 모르는 편이 낫다).
- 이미 하드까지 깼으면 라벨 `🔥 어려운 길 ✓`.
- 키보드 순회(`buttons` 배열, index.html:14740)에도 이 버튼이 들어가야 한다. 순서: 1장 카드 → 어려운 길 → 2장 카드 …
- 탭 시 이야기 컷신 없이 바로 `startCyclops({ hard: true })`.

### 6.3 진입/클리어

```js
function startCyclops(opts) {
  const hard = !!(opts && opts.hard);
  setCanvasLabel(hard
    ? '오디세우스가 폴리페모스에게 쫓기며 동굴을 달리는 어려운 길'
    : '오디세우스가 키클롭스 동굴에서 별길을 따라 달리는 게임');
  announce(hard
    ? '어려운 길. 위쪽 화살표로 점프, 아래쪽 화살표로 숙여요. 거인이 쫓아와요.'
    : '키클롭스 동굴. 스페이스바나 위쪽 화살표로 점프해요.');
  ODY.E.setScene(ODY.Stages.cyclops({ onClear: r => onCyclopsClear(r, hard), hard }));
}
```

`options.onClear`는 하드에서 `{ stars, lead }`를 넘긴다. 클리어 화면(`UI.ClearScene`)에 하드일 때 한 줄 추가: `'거인을 ' + Math.round(lead) + '만큼 따돌렸어요!'`, 첫 하드 클리어면 `'어려운 길을 처음 끝냈어요!'`.

## 7. 캐시

`site/sw.js`의 `CACHE_VERSION`을 `v52` → `v53`으로 올린다. `./odyssey/`는 이미 `CORE_SHELL`(sw.js:220)에 있으니 목록 변경은 없다.

## 8. 완료 기준

기능:
1. 일반 모드로 1장을 처음부터 끝까지 플레이 — 조작·속도·하트·거인 그림이 지금과 동일. 터치 버튼도 점프 하나만 보인다.
2. 하드 모드 진입 버튼은 1장을 깨기 전에는 **보이지 않는다**.
3. 하드에서 `hang`을 서서 통과하면 맞고, 숙여서 통과하면 안 맞는다. **점프로는 절대 못 피한다.**
4. 첫 `hang`(3720)은 데미지가 없고 힌트가 뜬다.
5. 공중에서 ↓를 누른 채 착지하면 자동으로 슬라이드가 이어진다. 11340 낙석 → 11380 손 구간이 한 번의 흐름으로 통과된다.
6. 슬라이드 중 점프하면 즉시 일어나며 점프한다.
7. 맞으면 거리 바가 26 줄고 거인이 눈에 띄게 커진다. 안 맞고 달리면 서서히 회복된다.
8. 거리 0 → 아테나 화면 → 체크포인트에서 `lead 62`로 재시작. 게임 오버 문구는 없다.
9. 하드 클리어 후 다시 스테이지 고르기로 가면 「🔥 어려운 길 ✓」.
10. 하드 클리어가 `wisdom`(지혜의 별)을 늘리지 않는다. 2장 해금 조건이 바뀌지 않는다.

호환:

12. 손상된/이상한 JSON을 넣어도 `normalizeProgress`가 튕기지 않는다.

접근성:
13. 아이패드 가로에서 점프·숙여 버튼을 **동시에** 눌러도 서로의 입력을 훔치지 않는다.
14. 음소거 상태면 포효가 나지 않는다. `prefers-reduced-motion`이면 추격 흔들림이 없다.
