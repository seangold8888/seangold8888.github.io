# 어벤져스 배포 시 공통 오프라인 코드 유지

2026-09-12 확인: `8fde154`에서 추가했던 공통 워커 이관 코드가 `521ea5c`의 게임 재빌드 배포 때 사라졌다. 그때 `/avengers/sw.js`도 다른 캐시를 모두 삭제하는 옛 버전으로 돌아갔다. 이후 카드 전체 검사에서 같은 오류가 반복됐다.

현재 `index.html`의 `avengers-worker-migration` 스크립트는 게임 번들보다 먼저 실행되어 번들의 `register("./sw.js")`를 공통 `../sw.js` 등록으로 연결한다. 공통 워커가 활성화된 뒤 어벤져스 범위의 등록만 해제하고 제어권을 다시 요청한다. 설치 실패 시 기존 등록은 유지되고 다음 호출에서 재시도한다.

이미 열린 문서는 등록 해제 후에도 옛 워커의 제어를 유지할 수 있다. 게임을 끊는 강제 새로고침은 하지 않으며 다음 방문부터 공통 워커가 제어한다. 실제 Edge에서 이 수명 주기를 확인했다.

`avengers/sw.js`는 이전 워커를 은퇴시키는 짧은 파일이다. 캐시 삭제, 캐시 읽기, fetch 처리를 다시 넣으면 안 된다. 게임을 재빌드할 때 이 두 배포 보정이 없어지지 않게 유지한다. 진행 기록인 localStorage는 이관 과정에서 수정하지 않는다.

검증 명령:

```powershell
node --test --test-name-pattern="Avengers migrates" cards/tests/pwa.test.js
node cards/tools/avengers-worker-smoke.cjs
node --test "cards/tests/*.test.js"
```

브라우저 검사는 Playwright와 Edge가 필요하다. 별도 로컬 서버·격리 컨텍스트에서 실제 워커의 루트/하위경로 이관, 설치 실패 후 재시도, 다른 캐시 및 진행 기록 보존을 검증한다. 사용자의 실제 브라우저 저장공간은 사용하지 않는다. 테스트에서는 그래픽·오디오 파일만 작은 대역 응답으로 대신하며 게임 플레이를 검증하는 검사는 아니다.

**이 실패를 더 이상 '정상적인 기존 오류'로 제외하지 않는다.**
