# 배경음악 슬롯

이 폴더에 음악 파일을 넣으면 그 곡이 재생된다. 파일이 없으면 코드로 합성한 오리지널 곡이 대신 나온다.
**코드 수정은 필요 없다. 파일 이름만 맞추면 된다.**

## 파일 이름

| 파일 이름 | 재생 시점 |
|---|---|
| `title.mp3` | 타이틀 화면 |
| `hero-select.mp3` | 영웅 선택 화면 |
| `stage-newyork.mp3` | 1스테이지 뉴욕 침공 |
| `stage-spiderverse.mp3` | 2스테이지 스파이더버스 균열 |
| `stage-asgard.mp3` | 3스테이지 아스가르드 폭풍 |
| `stage-core.mp3` | 4스테이지 멀티버스 코어 |
| `boss.mp3` | 보스 등장 시 |
| `victory.mp3` | 스테이지 클리어 |

확장자는 `.mp3`, `.ogg`, `.m4a`, `.wav` 중 아무거나 되고, 위 순서로 찾는다.
넣지 않은 슬롯은 자동으로 합성 곡으로 넘어간다. 일부만 넣어도 된다.

## 동작

- 파일은 자동으로 **반복 재생**된다. 곡 길이는 상관없다.
- 트랙이 바뀔 때 **0.55~0.9초 크로스페이드**한다.
- 합동 필살기가 나가면 음악이 잠깐 작아졌다가 돌아온다.
- 앱을 전환하거나 일시정지하면 음악도 멈춘다.
- 볼륨은 `M1Audio.setMusicVolume(0~1)`로 조절한다. 기본값 0.55.

## 음원에 대해

이 저장소에는 **제3자 음원을 넣지 않는다.** 상업 영화 사운드트랙을 포함해, 권리를 가지지 않은 음원을 이 폴더에 커밋하면 안 된다.

넣을 수 있는 것:
- 직접 만든 곡
- 정당하게 구매해 개인적으로 보유한 음원 (가족 내 비공개 사용 범위에서 본인 판단)
- 사용 허락된 라이선스 음원 (게임용 로열티프리 오케스트라 음원 등)

## 합성 곡 (기본값)

파일이 없을 때 나오는 곡은 `src/game/systems/MusicManager.ts`의 `SCORES`에 정의된 이 프로젝트 전용 오리지널이다.
제3자 샘플이나 영화 선율을 사용하지 않으며, 8곡 모두 16마디 A/B/브리지 형식과 서로 다른 조성·템포·모티프를 가진다. 현악 오스티나토, 브라스, 저음 타악기, 하이브리드 악센트, 리버브와 다이내믹 처리는 WebAudio로 실시간 합성한다.

| 트랙 | 성격 |
|---|---|
| `title` | D단조 92BPM, 상행 5도 팡파르 |
| `hero-select` | E장조 104BPM, 밝은 아르페지오 |
| `stage-newyork` | C단조 116BPM, 추진력 있는 행진 |
| `stage-spiderverse` | 124BPM 감5도 중심, 불안정한 차원 |
| `stage-asgard` | A단조 88BPM, 느리고 웅장 |
| `stage-core` | 132BPM, 반음 긴장 |
| `boss` | G단조 140BPM, 반음 반복 압박 |
| `victory` | F장조 100BPM, 상행 해결 |

곡을 고치려면 `SCORES`의 `bass`·`motif`·`motifB`·`bridge`·`pads` 배열(루트음 기준 반음 단위)과 `form`을 바꾸면 된다.
