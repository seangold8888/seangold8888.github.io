개인정보처리방침

시행일: 2026-10-22

1. 누가 쓰는 도구인가

zoopan youtube(이하 "도구")는 ZOOpan 운영자가 자기 소유의 유튜브 채널을 관리하기 위해 쓰는 개인용 도구입니다. 다른 사람의 구글 계정 로그인을 받지 않으며, 일반 이용자의 개인정보를 수집하지 않습니다.

2. 접근하는 구글 사용자 데이터

운영자가 구글 OAuth로 직접 승인한 범위 안에서 다음 데이터에만 접근합니다.

  • youtube.upload: 운영자 채널에 영상 업로드
  • youtube: 운영자 채널 영상의 공개 상태·예약·제목·설명·썸네일 관리
  • youtube.readonly: 운영자 채널의 영상 목록·조회수 확인

3. 사용 목적과 제한

위 데이터는 운영자 본인 채널의 영상 업로드와 관리에만 씁니다. 광고, 판매, 프로파일링, 제3자 제공에 쓰지 않으며, 사람이 따로 열람하는 일은 운영자 본인의 채널 관리에 필요한 경우로 한정합니다. 이 도구가 구글 API에서 받은 정보를 사용하고 다른 앱으로 전송하는 방식은 Google API 서비스 사용자 데이터 정책(제한적 사용 요구사항 포함)을 따릅니다.

4. 저장과 보관

OAuth 인증 토큰은 운영자 개인 PC에만 저장되며 외부 서버로 보내지 않습니다. 영상 파일과 업로드 기록도 운영자 PC에만 보관합니다. 운영자는 언제든 구글 계정 권한 페이지에서 이 도구의 접근 권한을 해제할 수 있고, 해제하면 토큰은 더 이상 쓸 수 없습니다. 로컬 토큰 파일은 해제와 함께 삭제합니다.

5. 유튜브 관련 고지

이 도구는 YouTube API 서비스를 사용합니다. 유튜브 이용에는 YouTube 서비스 약관과 Google 개인정보처리방침이 적용됩니다.
