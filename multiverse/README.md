# 재이와 태오의 멀티버스 2

2026-09-24. 옛 멀티버스(`/avengers/`, 2인 벨트스크롤)가 "재미없다"는 말을 듣고 새로 만든 혼자 하는 게임이다. 옛 게임은 주소만 남겨 두고 모험 상자 카드는 이쪽을 가리킨다.

## 핵심

- **주인공은 재이·태오 자신.** 한 명을 고르면 다른 한 명은 컴퓨터 동료로 따라와 싸운다.
- **한 판 90초.** 게임 시간 티켓 한 장(5분)에 세 판.
- **미션 3종 × 세계 4곳.** 친구 구출(철창 3개), 보물 모으기(반짝이 50개), 보스(거미 로봇 → 재윙 → 번개 골렘 → 쓰구미 메카). 보스를 이기면 다음 세계.
- **별 → 캡슐 → 꾸미기.** 별 3개로 캡슐, 캡슐은 아직 없는 조각만 준다(26개). 망토·마스크·가슴 마크·무기·필살기 색. 무기는 공격 방식을 바꾼다(방패=밀어내기·피해 감소, 망치=세 번째 타격 충격파, 빛검=긴 베기, 거미줄=멀리 쏘고 느리게).
- **조작.** 왼쪽 끌기 이동, 오른쪽 공격(가까운 적으로 저절로 돌아섬)·필살기. 키보드 WASD/방향키 + J/K.

## 파일

- `data.js` 세계·미션·영웅 기준점·적·보스·꾸미기 조각. 영웅 포즈 그림의 머리·가슴·어깨·손 기준점은 그림을 바꾸면 다시 맞춘다.
- `save.js` 저장·잠금·별·캡슐 규칙(순수 함수, `tests/save.test.js`).
- `game.js` 캔버스 엔진·화면. `window.__MV`로 점검 스크립트가 미션을 바로 시작한다.
- 그림: `tools/vertex-sprite-art.py`(Vertex, ADC)로 초록 배경에 그리고 `tools/mv-sprites.py`로 배경을 빼 `art/`에 webp로 둔다.
